## 三、代码索引

> Python 包命名空间均为 **`openjiuwen_runtime`**，按 monorepo 子目录安装。

| `management/` | `openjiuwen-runtime-management` | 0.1.0 | 部署策略与实例生命周期 |

| `applications/ir_execution_service/` | `ir-execution-service` | 0.1.0 | IR 执行服务 |

### 3.2 顶层目录结构

```
agent-runtime/
├── server/            # 管理面 FastAPI（部署/查询/删除）
├── management/        # DeploymentManager + subprocess/docker/k8s
├── service/           # AgentApp、PluginApp、REST 中间件
├── foundation/        # settings、DB handlers、port、docker、venv
├── applications/      # 具体 Agent 类型适配
├── cli/               # CLI 入口
├── docker/            # 镜像与 compose
└── scripts/           # run-server.sh|.ps1 等
```

### 3.3 Server 管理面（`server/openjiuwen_runtime/server/`）

| 文件 | 职责 |
|------|------|
| `main.py` | FastAPI 应用；`DeploymentManager` 初始化 |
| `middleware/tenant.py` | 租户上下文 `user_id` / `space_id` |
| `converter/agent_converter.py` | 部署请求转换 |
| `models/request.py` | 请求模型 |

**主要 REST 端点**（`main.py`）：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/health` | 健康检查 |
| POST | `/api/v1/agents/deploy` | 部署 Agent（支持上传 IR 等） |
| GET | `/api/v1/agents` | 列出部署 |
| GET | `/api/v1/agents/{deployment_id}` | 部署详情 |
| DELETE | `/api/v1/agents/{deployment_id}` | 删除部署 |

配置入口：`server/.env`（模板 `server/.env.example`），逻辑读取 `foundation.config.settings`。

### 3.4 Management（`management/openjiuwen_runtime/management/`）

| 路径 | 职责 |
|------|------|
| `manager.py` | `DeploymentManager`：部署、列表、删除、shutdown |
| `models/enums.py` | `DeployMode`、`DeploymentType`、`DeploymentStatus` |
| `models/deployment_params.py` | `DeployAgentParams`、`ListDeploymentsParams` |
| `deployments/subprocess/` | 子进程策略（默认） |
| `deployments/docker/` | Docker 容器策略 |
| `deployments/k8s/` | Kubernetes 策略 |
| `deployments/base/` | `Deployer` / `Strategy` 抽象 |

### 3.5 Service 对话面（`service/openjiuwen_runtime/service/`）

| 路径 | 职责 |
|------|------|
| `app/agent_app.py` | `AgentApp` 主类 |
| `app/base_app.py` | `BaseApp` 基类 |
| `app/restful.py` | REST 路由挂载 |
| `app/app_group.py` | 多应用组 |
| `app/plugin_app.py` | 插件应用 |
| `app/middleware.py` | 服务中间件 |
| `examples/` | `simple_agent_app.py` 等示例 |

**Agent 实例常见端点**（见 `docs/zh/4. Agent接入.md`）：`GET /health`、`POST /{prefix}/query`（SSE）、`POST /{prefix}/reset_conversation`。

### 3.6 Foundation（`foundation/openjiuwen_runtime/foundation/`）

| 路径 | 职责 |

| `config.py` | `settings`（`DB_TYPE`、`DEPLOY_TYPE`、`IP`、`PORT` 等） |
| `db/sqlite_handler.py`、`mysql_handler.py` | 部署记录持久化 |
| `db/redis_handler.py` | 可选 Redis |
| `port_utils.py` | 端口分配与检测 |
| `docker_utils.py` | Docker 操作辅助 |
| `venv_manager.py`、`packaging.py` | 虚拟环境与打包 |
| `log/` | 日志配置 |

### 3.7 Applications（`applications/`）

| 目录 | 职责 |
|------|------|
| `lowcode_agent/` | `lowcode_agent_runner.py`、`runtime_agent_adapters.py`、IR 注册 |
| `ir_execution_service/` | IR 拉取、执行环境、`stream_api.py`、`react_agent_builder.py` |
| `workflow_agent/` | 工作流 Agent 示例 |
| `llm_agent/` | LLM Agent 示例 |

### 3.8 CLI 与脚本

| 路径 | 职责 |
|------|------|
| `cli/openjiuwen_runtime/cli/main.py` | CLI 入口 |
| `scripts/run-server.sh` / `run-server.ps1` | 启动 Runtime Server |
| `server/deploy.sh` / `deploy.bat` | 部署辅助 |

### 3.9 概念对照

| 概念 | 首选位置 | 勿混淆 |
|------|----------|--------|
| Runtime Server（管理面） | `server/.../main.py` | Agent 进程内的 `service` 对话 API |
| 部署策略 | `management/deployments/*` | `server` 仅暴露 HTTP |
| `DEPLOY_TYPE` / `mode=docker` | `foundation.config`、`docs/zh/3. Agent部署.md` | Studio 前端部署是另一产品 |
| 低码 IR 部署 | `applications/lowcode_agent`、`ir_execution_service` | agent-core 工作流引擎在依赖 SDK 中 |

## 五、建议调查顺序

1. **文档**：`docs/zh/0~4` 中与任务相关的最小子集。
2. **配置**：`server/.env.example` + `docs/zh/2. 配置说明.md`。
3. **管理面**：`server/.../main.py` → `management/manager.py` → 对应 `deployments/<mode>/`。
4. **对话面**：`service/.../agent_app.py` + `docs/zh/4. Agent接入.md`。
5. **应用类型**：`applications/<type>/`。
