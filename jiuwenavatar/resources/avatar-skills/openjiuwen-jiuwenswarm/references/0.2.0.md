## 三、代码索引

> 主 Python 包为 **`jiuwenclaw`**；对外 PyPI 名 **`jiuwenswarm`**。CLI 入口见 `pyproject.toml` 的 `[project.scripts]`。

### 3.1 进程与入口

| 命令 / 模块 | 职责 | 关键文件 |
|-------------|------|----------|
| `jiuwenswarm-init` | 工作区初始化 | `jiuwenclaw/init_workspace.py` |
| `jiuwenswarm-start` | 启动 Gateway + AgentServer 等 | `jiuwenclaw/start_services.py` |
| `jiuwenswarm-gateway` | Gateway 进程 | `jiuwenclaw/gateway/app_gateway.py` |
| `jiuwenswarm-agentserver` | AgentServer 进程 | `jiuwenclaw/server/app_agentserver.py` |
| `jiuwenswarm-web` | Web 频道 | `jiuwenclaw/channels/web/app_web.py` |
| `jiuwenswarm-desktop` | 桌面 WebView | `jiuwenclaw/channels/desktop/desktop_app.py` |
| `jiuwenswarm-tui` / `jiuwenswarm-acp` | TUI / ACP | `jiuwenclaw/channels/acp/app_acp.py` |
| `jiuwenswarm-app` | 聚合应用入口 | `jiuwenclaw/app.py` |

### 3.2 `jiuwenclaw` 顶层结构

```
jiuwenclaw/
├── gateway/           # 消息路由、IM 频道、Slash、心跳、定时任务
├── server/            # AgentServer：runtime、session、skill、gateway_push
├── agents/harness/    # DeepAgent 变体：claw/code、team、tools、rails、memory
├── channels/          # web、desktop、acp(tui)
├── common/            # e2a 协议、schema、security
├── instance_manager/  # 单机多实例
├── resources/agent/   # 预置技能与工作区模板
└── extensions/        # SDK 扩展挂载
```

### 3.3 Gateway（`jiuwenclaw/gateway/`）

| 目录 / 文件 | 职责 |
|-------------|------|
| `app_gateway.py` | Gateway 应用入口 |
| `routing/agent_client.py` | 与 AgentServer 通信 |
| `routing/session_map.py`、`route_binding.py` | 会话与路由绑定 |
| `message_handler/message_handler.py` | 入站消息处理 |
| `message_handler/command_parser/slash_command.py` | Slash 命令 |
| `channel_manager/` | IM 平台适配（飞书、钉钉、企微、Discord 等） |
| `im_pipeline/` | 入站/出站 IM 流水线 |
| `heartbeat/` | 心跳 |
| `cron/` | 定时任务 |

### 3.4 AgentServer（`jiuwenclaw/server/`）

| 目录 / 文件 | 职责 |
|-------------|------|
| `app_agentserver.py` | AgentServer 入口 |
| `agent_ws_server.py` | WebSocket 服务 |
| `runtime/agent_manager.py` | Agent 生命周期与配置 |
| `runtime/agent_adapter/` | `interface_deep`、`interface_code`、演进与 Team 辅助 |
| `runtime/session/` | 会话历史与元数据 |
| `runtime/skill/skill_manager.py` | 技能加载与管理 |
| `runtime/skill/skilldev/` | 技能开发与自演进流水线 |
| `gateway_push/` | 向 Gateway 推送（transport、wire） |

### 3.5 Agent Harness（`jiuwenclaw/agents/harness/`）

| 目录 | 职责 |
|------|------|
| `claw/` | 主 Claw DeepAgent 模式 |
| `code/` | 编码模式 Agent |
| `team/` | `team_manager.py`、`config_loader.py`、`distributed_runtime.py`、`a2x/` |
| `common/tools/` | Shell、浏览器、小艺手机工具等 |
| `common/rails/` | permissions、project_memory 等 |
| `common/memory/` | 记忆引擎集成 |
| `common/auto_harness/` | 自动化 harness 辅助 |

### 3.6 频道与协议（`channels/`、`common/e2a/`）

| 路径 | 职责 |
|------|------|
| `channels/web/` | Web UI 后端 |
| `channels/desktop/` | 桌面壳 |
| `channels/acp/` | TUI / ACP 客户端 |
| `common/e2a/acp/` | E2A ACP 编解码 |
| `common/schema/` | 消息与配置 schema |

### 3.7 其它仓库内组件

| 路径 | 职责 |
|------|------|
| `jiuwenbox/` | JiuwenBox 子产品（独立 `src/jiuwenbox`） |
| `packages/jiuwenswarm-tui/` | TUI 可选依赖包 |
| `docker/` | 容器化部署 |
| `scripts/` | 构建 exe、NFS、Gateway ACP 启动脚本 |

### 3.8 概念对照（避免搜错）

| 概念 | 首选代码位置 | 勿混淆 |
|------|----------------|--------|
| Gateway | `jiuwenclaw/gateway/` | `server/gateway_push/` 为 Server→Gateway 推送 |
| AgentServer | `jiuwenclaw/server/` | `agentserver` 为进程名，非独立顶层包 |
| Team / 分布式 | `agents/harness/team/` | openjiuwen `core/multi_agent` 在依赖 SDK 内 |
| 工作区目录 | `init_workspace`、文档 `智能体.md` | 用户目录 `.jiuwenswarm/` |
| E2A | `common/e2a/` | A2A 见 `a2x` 与 `docs/zh/A2A.md` |
