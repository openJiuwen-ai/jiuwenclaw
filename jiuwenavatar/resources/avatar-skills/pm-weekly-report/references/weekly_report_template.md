# 周报模板

> 本模板为 `pm-weekly-report` Skill 的标准输出结构参考。
> 实际生成时根据项目规模和周期调整内容详细程度。

## 使用说明

1. 模板中的 `<>` 为占位符，生成时替换为实际内容
2. 表格中的示例行在生成时删除
3. 无内容的章节可标注"无"或"暂无"
4. 报告语言与用户输入语言保持一致

## 周报 vs 月报

| 维度 | 周报 | 月报 |
|------|------|------|
| 粒度 | 任务级别 | 里程碑级别 |
| 风险 | 当前阻塞项 | 趋势分析 |
| 度量 | 本周数据 | 月度趋势 |
| 篇幅 | 1-2 页 | 2-4 页 |
| 受众 | 项目组 | 管理层 + 项目组 |
