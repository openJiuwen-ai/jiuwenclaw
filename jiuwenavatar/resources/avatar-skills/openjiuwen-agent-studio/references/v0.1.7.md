# Reference — openJiuwen Studio v0.1.7

本文件用于从用户任务跳到**最小相关**文档、前后端实现、运维资产与测试。所有路径均相对于 **`assets/v0.1.7/`**。

文档为**中英双语**：`docs/zh/` 与 `docs/en/` 各有一套；英文目录名含**空格**（如 `2.Installation Guide`、`4.Development Guide`），以磁盘实际文件夹名为准。

**版本提示**：前端产品线版本见 `frontend/package.json`（`0.1.7`，`name`: `jiuwen-agent-studio`）；后端 Python 包 `openjiuwen-studio` 见 `backend/pyproject.toml`（`0.1.5`）；运行时依赖 `openjiuwen[chromadb,obs]==0.1.10`。前后端版本字段可能不一致，以各 `package.json` / `pyproject.toml` 为准。

## 三、代码索引

> 公开 API 以 `routers/`、`schemas/`、`main.py` 路由注册与各模块 docstring 为准；Studio 后端通过 `openjiuwen` SDK 执行工作流与智能体，**勿与 agent-core 技能包路径混读**。

### 3.1 顶层包结构

```
assets/v0.1.7/
├── backend/openjiuwen_studio/   # FastAPI 主服务
├── frontend/                    # Vite + React 主应用 + workspace packages
├── plugin_server/               # 独立插件 REST 服务
├── sandbox_server/              # 代码沙箱 server + gateway
├── scripts/                     # Docker 部署/升级脚本
├── docker/                      # 各组件 Dockerfile
├── helm/studio/                 # K8s umbrella chart
└── docs/                        # 中英产品文档
```

### 3.2 `backend/openjiuwen_studio/` 目录与关键文件

| 目录 / 文件 | 职责 | 关键入口 |
|-------------|------|----------|
| `main.py` | FastAPI 入口、lifespan、路由挂载 | 读 `routers/register.py` |
| `memory_engine_start.py` | 记忆引擎启动 | — |
| `conf/` | 运行时 YAML/JSON 配置 | `config.yaml`, `config.json` |

| `schemas/` | Pydantic 请求/响应 | 与 `routers/`、`models/` 一一对应 |
| `ops/` | Ops DB 域（提示词/LLM 配置） | `modules/prompt/`, `modules/llm/` |

## 八、建议调查顺序（文档优先）

1. **文档**：`docs/zh/SUMMARY.md` 或 `docs/en/SUMMARY.md` → 本节「二」最小子集。
2. **任务路由**：本节「一」按意图表 → 锁定文档 + 代码路径。
3. **后端**：`routers/` → `core/manager/` → `core/executor/` 或 `core/dsl_converter/`。
4. **前端**：`src/pages/<模块>/` → `api-client/src/services/` → 画布问题下钻 `packages/workflow-canvas/`。
5. **部署**：安装文档 + 「六」`scripts/` / `docker/` / `helm/`。
6. **边界**：「五」单测；行为仍不确定再对照 `openjiuwen` SDK 行为（`backend/pyproject.toml` 声明版本）。
