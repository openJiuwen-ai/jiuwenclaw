# 对话降级（仅无提问工具时）

当且仅当当前会话 **确实没有** 可用的 `AskUserQuestion` / `AskQuestion`（或等价工具）时，允许在对话中等待用户输入。有工具时 **禁止** 用本降级。

## 判定「无工具」（满足其一）

1. 工具列表中 **不存在** 上述工具名；**或**
2. 已尝试调用，返回 **unknown tool / not found**（非用户取消）。

**不算**无工具：需要用户思考、关闭弹窗、hook 拒绝、选项填错、payload 可修正、超时。应修正 payload 并重试工具（≤2 次），仍失败再 fallback 并注明原因。

## 降级步骤

1. **结束本回合**；勿继续 Gate 或重派子 agent。  
2. 开头：`[user-interact: chat-fallback]` + 一行说明无工具。  
3. 与工具路径 **相同** 的 `prompt`、**编号选项**（A/B/C…）+「其他」、`question_id`。  
4. **每次只问 1 题**；结尾：「请选择或说明其他；收到回复前流水线暂停。」  
5. 用户 **下一条消息** = 答案 → 写入 [record-templates.md](record-templates.md)（与工具路径相同规则）→ 恢复编排。

## 禁止

- 有工具却 Markdown 提问（假降级）
- 未检查工具就说「需要等用户输入」
- 未收到回复就写「用户决定」或 Gate PASS
- 边问边执行后续阶段
- G0 问「是否启动完整流水线」

## 恢复

后续回合若工具可用，**必须**改回结构化工具；不得因曾降级而永久用对话提问。
