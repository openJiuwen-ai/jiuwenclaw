## 三、代码索引

> 主 Python 包：**`openjiuwen_deepsearch`**（命名空间包，子目录可无 `__init__.py`）。

### 3.1 顶层结构

```
deepsearch/
├── openjiuwen_deepsearch/   # SDK：算法 + 工作流框架
├── server/                  # FastAPI 后端（完整版）
├── main.py                  # SDK 主入口脚本
├── start_backend.py         # 后端启动
├── docker/                  # 容器构建
├── tools/                   # 统计/日志可视化等
└── tests/                   # 测试（镜像模块）
```

### 3.2 `openjiuwen_deepsearch/algorithm/` — 核心算法

| 目录 | 职责 | 关键文件 |
|------|------|----------|
| `query_understanding/` | 澄清、大纲、章节计划、路由 | `router.py`、`outliner.py`、`planner.py`、`interpreter.py` |
| `research_collector/` | 检索资料收集与评估 | `collector_function.py`、`doc_evaluation.py` |
| `report/` | 报告生成 | `report.py`、`report_utils.py` |
| `report_template/` | 模板解析与生成 | `template_generator.py` |
| `source_trace/` | 溯源、引用校验 | `source_tracer.py`、`citation_verify_research.py` |
| `source_tracer_infer/` | 溯源推理与 HTML | `infer.py`、`generate_html.py` |
| `user_feedback_processor/` | 反馈驱动的局部改写 | `user_feedback_processor.py`、`supplementary_search.py`、`synonym_rewrite.py` |
| `search_agent/` | Agent 封装与状态解析 | `deepsearch_agent.py` |
| `prompts/` | 各阶段 `.md` 提示词模板 | — |
| `chart_generation/` | 图表生成 | `sandbox/` 等 |

### 3.3 `openjiuwen_deepsearch/framework/openjiuwen/` — 工作流框架

| 目录 | 职责 | 关键文件 |
|------|------|----------|
| `agent/` | 主工作流与节点 | `workflow.py`、`main_graph_nodes.py`、`agent_factory.py`、`base_node.py` |
| `agent/collector_graph/` | 信息收集子图 | `info_collector.py`、`graph_builder.py` |
| `agent/reasoning_writing_graph/` | 编辑/写作子图 | `editor_team_nodes.py` |
| `core/workflow_agent/` | WorkflowAgent 控制器 | `workflow_agent.py`、`workflow_controller.py` |
| `tools/` | 搜索工具 | `web_search.py`、`local_search.py` |
| `tools/search_api/` | 外部引擎 | `tavily/`、`serper/`、`jina/`、`xunfei/`、`local_search_api/` 等 |
| `tools/runtime_api/` | Runtime 对接 | `runtime_api.py` |
| `llm/` | 模型工厂 | `llm_model_factory.py` |

### 3.4 配置与公共模块

| 路径 | 职责 |
|------|------|
| `config/config.py` | `LLMConfig`、`AgentConfig`、`ServiceConfig` 等 |

| `common/exception.py`、`status_code.py` | 异常与状态码 |
| `utils/log_utils/`、`common_utils/` | 日志、流式、文本工具 |

| 路径 | 职责 |
|------|------|
| `main.py` | FastAPI 应用入口 |

| `deepsearch/core/manager/` | 业务 Manager（含 `report_manager/`） |
| `local_retrieval/` | 本地检索、解析、存储 |
