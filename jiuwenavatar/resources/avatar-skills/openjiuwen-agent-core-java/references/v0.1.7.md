## 三、代码索引

> 路径均相对于 `src/main/java/com/openjiuwen/`（完整前缀为 `assets/v0.1.7/src/main/java/com/openjiuwen/`）。公开 API 以中文 API 文档与源码为准；`legacy/` 仅兼容，勿在新功能中依赖。

### 3.1 顶层包结构

```
com.openjiuwen/
├── core/              # SDK 运行时：工作流、单智能体、Session、Runner、检索、记忆等
├── agent_evolving/    # 智能体演进：轨迹、Trainer、Optimizer
├── deepagents/        # DeepAgent 工厂与中间件（Java 侧轻量封装）
├── dev_tools/         # tune、prompt_builder、skill_creator
├── extensions/        # checkpointer、store、context_evolver、厂商适配
└── spi/               # Store 等 SPI 扩展点
```

**构建事实**：`pom.xml` → Java 21；`groupId` `com.openjiuwen`，`artifactId` `agent-core-java`，`version` `0.1.7`。
