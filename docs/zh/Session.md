# 会话管理（Session）

本文档说明 JiuwenSwarm 的会话（Session）管理功能。

## 会话是什么

会话是用户与 Agent 之间的一次连续对话上下文，包含历史消息与中间状态。

## 新建会话

- 在会话列表中点击「新建会话」
- 新会话拥有独立的上下文，与历史会话互不影响

## 会话历史

- 所有会话保存在会话列表中，可随时切换查看
- 会话数据存储在用户目录下的 JiuwenSwarm 数据目录中

## 会话恢复

- 重启服务后，历史会话仍可从会话列表恢复
- 会话恢复依赖会话元数据（metadata）文件，请勿手动编辑

## 常见问题

### 会话列表无法加载

- 检查会话元数据文件是否损坏（如异常退出导致）
- 如遇损坏，可将损坏的会话数据备份后移出数据目录，再重启服务
- 反馈问题请附上 `~/.jiuwenswarm/agent/.logs` 下的日志

### 会话内容丢失

- 检查数据目录是否被清理或移动
- 升级版本前建议备份数据目录
