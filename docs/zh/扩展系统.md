# 扩展系统

> 本文档描述 JiuwenClaw 的扩展（Extension）系统架构与开发指南。

## 1. 概述

扩展系统允许开发者在不修改 JiuwenClaw 核心代码的情况下增强功能。扩展（Extension）是一个自包含的 Python 包，可以：

- 注册事件回调，在 Agent 生命周期的特定阶段执行自定义逻辑
- 提供自定义的 AgentServerClient 实现（替换默认的 WebSocket 通信）
- 提供自定义的加解密实现（CryptoProvider）
- 访问 ExtensionRegistry 注册事件处理器
- 声明自身的依赖（自动安装）

## 2. 架构

```
┌─────────────────────────────────────────────────────────────┐
│                    ExtensionManager                          │
│  管理扩展的生命周期：加载、初始化、关闭                       │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐    │
│  │                ExtensionLoader                       │    │
│  │  扫描搜索目录 → 发现扩展根目录 → 加载扩展模块       │    │
│  │  自动安装依赖 → 调用 register_extensions()          │    │
│  └─────────────────────────────────────────────────────┘    │
│                                                             │
│  ┌─────────────────────────────────────────────────────┐    │
│  │              ExtensionRegistry (单例)                │    │
│  │  注册事件回调 · 管理 AgentServerClient 扩展         │    │
│  │  管理 CryptoUtility 扩展 · 触发事件                 │    │
│  └─────────────────────────────────────────────────────┘    │
└─────────────────────────────────────────────────────────────┘
```

### 2.1 核心组件

| 组件 | 类/文件 | 职责 |
|------|---------|------|
| **ExtensionManager** | `extensions/manager.py` | 扩展生命周期管理：加载所有扩展、关闭所有扩展 |
| **ExtensionLoader** | `extensions/loader.py` | 扫描搜索目录、发现扩展根、加载 Python 模块、安装依赖 |
| **ExtensionRegistry** | `extensions/registry.py` | 单例注册中心，管理事件回调和 SDK 组件注册 |
| **BaseExtension** | `extensions/sdk/base.py` | 所有扩展的抽象基类，提供元数据和配置加载 |
| **AgentServerClientExtension** | `extensions/sdk/agent_server_client.py` | 自定义 AgentServer 客户端的扩展基类 |
| **CryptoUtility** | `extensions/sdk/crypto_utility.py` | 自定义加解密的扩展基类 |

## 3. 扩展目录结构

一个扩展是一个包含特定文件的目录。典型的扩展目录结构如下：

```
my_extension/
  ├── extension.yaml        # 清单文件（必需）：扩展元数据
  ├── extension.py          # 入口脚本（必需）：实现 register_extensions()
  ├── config.yaml           # 配置文件（可选）：扩展的默认配置
  ├── ...                   # 其他 Python 模块和资源
```

## 4. 扩展清单 (extension.yaml)

`extension.yaml` 是扩展的元数据文件，格式如下：

```yaml
id: my-extension                    # 扩展唯一标识
name: My Extension                  # 扩展显示名称
version: 1.0.0                      # 扩展版本
description: 这是一个示例扩展        # 扩展描述
author: Your Name                   # 扩展作者
min_jiuwenclaw_version: 0.1.8       # 最小兼容的 JiuwenClaw 版本
dependencies:                       # Python 包依赖（可选）
  requests: ">=2.28.0"
  beautifulsoup4: ">=4.12.0"
config_schema:                      # 配置模式（可选，JSON Schema）
  type: object
  properties:
    api_url:
      type: string
```

## 5. 入口脚本 (extension.py)

扩展必须提供 `extension.py` 作为入口脚本，并实现 `register_extensions()` 函数。

### 5.1 基本事件回调扩展

```python
# extension.py
from jiuwenclaw.extensions.registry import ExtensionRegistry
from jiuwenclaw.extensions.types import ExtensionConfig
from jiuwenclaw.extensions.sdk.base import BaseExtension


class MyExtension(BaseExtension):
    async def initialize(self, config: ExtensionConfig) -> None:
        """扩展初始化"""
        self.logger = config.logger
        self.logger.info("[MyExtension] 初始化完成")

    async def shutdown(self) -> None:
        """扩展关闭，释放资源"""
        pass


# 这是扩展的入口函数，必须实现
async def register_extensions(registry: ExtensionRegistry):
    """注册扩展到注册中心

    Args:
        registry: 扩展注册中心实例

    Returns:
        注册的扩展实例（或扩展实例列表）
    """
    ext = MyExtension()

    # 注册事件回调
    registry.register("on_agent_message", handle_agent_message, priority=100)

    return ext


async def handle_agent_message(context):
    """处理 Agent 消息的事件回调"""
    print(f"收到 Agent 消息: {context}")
```

### 5.2 自定义 AgentServerClient 扩展

```python
# extension.py
from jiuwenclaw.extensions.registry import ExtensionRegistry
from jiuwenclaw.extensions.sdk.agent_server_client import AgentServerClientExtension
from jiuwenclaw.gateway.agent_client import AgentServerClient
from jiuwenclaw.e2a.models import E2AEnvelope
from jiuwenclaw.schema.agent import AgentResponse, AgentResponseChunk


class MyAgentClient(AgentServerClient):
    """自定义 AgentServer 客户端实现"""

    async def connect(self) -> None:
        pass

    async def send_request(self, envelope: E2AEnvelope) -> str:
        pass

    async def close(self) -> None:
        pass


class MyClientExtension(AgentServerClientExtension):
    def __init__(self):
        self._client = MyAgentClient()

    def get_client(self) -> AgentServerClient:
        return self._client

    async def initialize(self, config) -> None:
        await self._client.connect()

    async def shutdown(self) -> None:
        await self._client.close()


async def register_extensions(registry: ExtensionRegistry):
    ext = MyClientExtension()
    registry.register_agent_server_client(ext)
    return ext
```

### 5.3 自定义加解密扩展

```python
# extension.py
from jiuwenclaw.extensions.registry import ExtensionRegistry
from jiuwenclaw.extensions.sdk.crypto_utility import CryptoUtility
from jiuwenclaw.security.base_crypto import CryptoProvider


class MyCrypto(CryptoProvider):
    def encrypt(self, plaintext: str, **kwargs) -> str:
        # 自定义加密逻辑
        return plaintext[::-1]  # 示例：反转字符串

    def decrypt(self, ciphertext: str, **kwargs) -> str:
        # 自定义解密逻辑
        return ciphertext[::-1]  # 示例：反转回来


class MyCryptoExtension(CryptoUtility):
    def __init__(self):
        self._crypto = MyCrypto()

    def get_crypto(self) -> CryptoProvider:
        return self._crypto

    async def initialize(self, config) -> None:
        pass

    async def shutdown(self) -> None:
        pass


async def register_extensions(registry: ExtensionRegistry):
    ext = MyCryptoExtension()
    registry.register_crypto_utility(ext)
    return ext
```

## 6. 配置

### 6.1 config.yaml 中的扩展配置

在 `config.yaml` 中配置扩展搜索目录：

```yaml
extensions:
  extension_dirs:
    - ~/.jiuwenclaw/extensions    # 用户扩展目录
    - /opt/my-extensions          # 其他扩展目录
```

扩展自身的配置可以放在其目录下的 `config.yaml` 中，通过 `_load_config_from_yaml()` 加载。

### 6.2 配置热更新

通过 `config.py` 的 `update_extension_config()` 方法可动态更新扩展配置。

## 7. 事件系统

扩展通过 ExtensionRegistry 注册事件回调，支持的事件类型包括（以 `openjiuwen` 的 `AsyncCallbackFramework` 支持的事件为准）：

| 事件 | 触发时机 |
|------|----------|
| `on_agent_start` | Agent 开始处理消息时 |
| `on_agent_message` | Agent 产生消息时 |
| `on_agent_tool_call` | Agent 调用工具时 |
| `on_agent_tool_result` | 工具调用返回结果时 |
| `on_agent_end` | Agent 处理完成时 |
| `on_session_create` | 创建新会话时 |
| `on_session_end` | 会话结束时 |

注册示例：

```python
# 注册事件回调，priority 越小优先级越高（默认 100）
registry.register("on_agent_start", my_handler, priority=50)

# 注销事件回调
registry.unregister("on_agent_start", my_handler)

# 手动触发事件
await registry.trigger("on_agent_message", context=my_context)
```

## 8. 扩展加载流程

```
JiuwenClaw 启动
  │
  ▼
读取 config.yaml 中 extensions.extension_dirs
  │
  ▼
ExtensionManager._setup_search_paths()
  │
  ▼
ExtensionLoader.discover_extension_roots()
  │  扫描每个搜索目录的子目录
  │  检测 extension.yaml 或 extension.py 存在
  │
  ▼（对每个扩展）
ExtensionLoader.load_extension(root)
  │
  ├── 1. 读取 extension.yaml（清单信息）
  ├── 2. 安装声明依赖（如缺失）
  ├── 3. 动态导入 extension.py 模块
  ├── 4. 调用 register_extensions(registry)
  │   ├── 注册事件回调
  │   ├── 注册 AgentServerClient
  │   └── 注册 CryptoUtility
  └── 5. 调用扩展的 initialize(config)
  │
  ▼
扩展加载完成，进入服务运行
```

## 9. SDK 参考

### BaseExtension

```python
class BaseExtension(ABC):
    async def initialize(self, config: ExtensionConfig) -> None  # 必须实现
    async def shutdown(self) -> None                             # 必须实现

    # 属性
    metadata -> ExtensionMetadata   # 从 extension.yaml 自动加载
    _extension_dir -> Path          # 扩展根目录

    # 方法
    set_extension_dir(path: Path)           # 手动设置扩展目录
    _load_config_from_yaml() -> dict        # 加载扩展的 config.yaml
```

### ExtensionConfig

```python
@dataclass
class ExtensionConfig:
    config: dict[str, Any]          # 全局配置字典
    logger: Any                     # 日志记录器
```

### ExtensionMetadata

```python
@dataclass
class ExtensionMetadata:
    id: str                         # 扩展唯一标识
    name: str                       # 扩展名称
    version: str                    # 扩展版本
    description: str                # 扩展描述
    author: str                     # 扩展作者
    min_jiuwenclaw_version: str     # 最小兼容版本

```

## 10. 最佳实践

1. **错误处理** — 扩展初始化失败不应阻止 JiuwenClaw 主程序启动，建议在 `register_extensions()` 中使用 try/except
2. **资源清理** — 务必在 `shutdown()` 中释放所有资源（关闭连接、清理临时文件等）
3. **日志** — 使用 ExtensionConfig 提供的 logger，而不是直接使用 print
4. **版本兼容** — 在 `extension.yaml` 中正确设置 `min_jiuwenclaw_version`
5. **轻量加载** — 避免在模块导入时执行耗时操作，使用 `initialize()` 进行初始化
6. **依赖管理** — 优先使用 Python 标准库，外部依赖声明在 `extension.yaml` 中
