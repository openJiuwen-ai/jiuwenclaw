# 定时任务（Scheduled Tasks）

JiuwenSwarm 支持定时任务，可按照设定的时间周期自动触发 Agent 执行任务。

## 功能入口

- 在界面顶部的「定时任务」页面进入
- 支持手动创建与表单创建两种方式

## 创建定时任务

1. 打开「定时任务」页面，点击创建
2. 填写任务名称与触发规则（cron 表达式或预设周期）
3. 选择要执行的任务/Agent 及参数
4. 保存后任务将按规则触发

## 时区说明

- 定时任务按服务器系统时区触发
- 如需按本地时间触发，请确保系统时区设置正确（如 `Asia/Shanghai`）
- 跨时区用户请留意系统时区与本地时区的偏差

## 触发记录

- 每次触发的记录可在定时任务页面查看
- 详细日志位于 `~/.jiuwenswarm/logs/`

## 常见问题

### 任务没有按时触发

- 检查系统时区设置
- 检查服务是否在运行（`uv run jiuwenswarm-start`）
- 查看 `~/.jiuwenswarm/logs/` 下的触发日志

### 触发时间与预期不符

- 确认 cron 表达式是否使用了本地时区对应的时刻
- 确认服务器系统时区是否为预期时区
