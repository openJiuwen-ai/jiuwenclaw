# 配置说明

JiuwenSwarm 的配置来源包括：`config/config.yaml`、`.env` 环境变量、以及 Web 前端各面板。本文档说明**哪些可在前端配置**、**哪些需手动修改文件**，以及各配置项的作用。

---

## 一、前端配置面板可配置

以下配置可通过 Web 端对应面板修改并保存，系统会自动写回配置文件或 `.env`。

**入口**：左侧导航 → **配置**

![配置信息](../assets/images/config.png)

**保存目标**：`.env`（环境变量）

| 配置项 | 环境变量 | 说明 |
|--------|----------|------|
| `api_base` | `API_BASE` | 模型 API 基础地址（如 `https://api.deepseek.com`） |
| `api_key` | `API_KEY` | 模型 API 密钥 |
| `model` | `MODEL_NAME` | 模型名称（如 `deepseek-chat`） |
| `model_provider` | `MODEL_PROVIDER` | 模型提供商（如 `OpenAI`） |
| `embed_api_base` | `EMBED_API_BASE` | Embed 服务 API 地址 |
| `embed_api_key` | `EMBED_API_KEY` | Embed 服务 API 密钥 |
| `embed_model` | `EMBED_MODEL` | Embed 模型名称 |
| `video_model` | `VIDEO_MODEL_NAME` | 视频处理调用模型 |
| `audio_model` | `AUDIO_MODEL_NAME` | 音频处理调用模型 |
| `vision_model` | `VISION_MODEL_NAME` | 图像处理调用模型 |
| `image_gen_model` | `IMAGE_GEN_MODEL_NAME` | 图片生成模型 |
| `jina_api_key` | `JINA_API_KEY` | Jina 搜索 API 密钥 |
| `serper_api_key` | `SERPER_API_KEY` | Serper 搜索 API 密钥 |
| `perplexity_api_key` | `PERPLEXITY_API_KEY` | Perplexity API 密钥 |
| `github_token` | `GITHUB_TOKEN` | GitHub Personal Access Token；SkillNet 搜索/安装走 GitHub API |
| `free_search_proxy_url` | `FREE_SEARCH_PROXY_URL` | 免费搜索和网页抓取使用的可选 HTTP/HTTPS 代理，例如 `http://username:password@proxyhk.huawei.com:8080` |
| `evolution_auto_scan` | `EVOLUTION_AUTO_SCAN` | 是否每轮对话后自动扫描可演进技能（`true`/`false`） |

**说明**：保存后后端会重启以加载新配置。模型配置（`api_base`、`api_key`、`model`、`model_provider`）为必填项。

## 二、前端不可配置

以下配置需通过**直接编辑 `config/config.yaml`** 或 **`.env`** 修改，无 Web 界面。

### 1. config.yaml 中仅文件可改的项

| 路径 | 说明 |
|------|------|
| `react.agent_name` | Agent 名称，默认 `main_agent` |
| `react.max_iterations` | 最大迭代轮数，默认 100 |
| `react.context_engine_config.enable_reload` | 是否启用上下文重载 |
| `react.evolution.enabled` | 是否启用 Skills 在线自演进 |
| `react.evolution.skill_base_dir` | Skill 根目录，默认 `agent/skills` |
| `tools` | 启用的工具列表（如 `todo`、`skill`） |
| `browser.remote_debugging_address` | 远程调试地址 |
| `browser.remote_debugging_port` | 远程调试端口 |
| `browser.user_data_dir` | Chrome 用户数据目录 |
| `browser.profile_directory` | Chrome 配置文件目录 |

另见：
- [模式配置](Modes.md) — `modes` 配置段
- [工具权限与安全](ToolPermissionsSecurity.md) — `permissions` 配置段

### 2. models 配置段（多模型配置）

可配置多个模型 Profile，分别用于主 Agent、视频、音频、视觉、图像生成等场景。

| 路径 | 说明 |
|------|------|
| `models.default.model_client_config` | 默认（主）模型连接配置：`api_base`、`api_key`、`model_name`、`client_provider`、`timeout`、`verify_ssl`、`custom_headers` |
| `models.default.model_config_obj` | 默认模型生成参数：`temperature` 等 |
| `models.video.model_client_config` | 视频处理模型 |
| `models.audio.model_client_config` | 音频处理模型 |
| `models.vision.model_client_config` | 视觉 / 图像理解模型 |
| `models.image_gen.model_client_config` | 图像生成模型 |
| `models.image_gen.model_config_obj` | 图像生成参数：`temperature` 等 |

每个子模型段均支持相同的 `model_client_config` 键：`api_base`、`api_key`、`model_name`、`client_provider`、`timeout`、`verify_ssl`。全部支持环境变量替换（如 `${VIDEO_API_BASE}`）。

### 3. memory.external 配置段（外接记忆）

| 路径 | 说明 |
|------|------|
| `memory.engine` | 引擎开关：`builtin` \| `external` \| `both` \| `none` |
| `memory.external.provider` | Provider 名称：`openjiuwen` \| `mem0` \| `openviking` \| `<plugin>` |
| `memory.external.user_id` | 数据隔离标识 |
| `memory.external.scope_id` | Scope 标识 |

详见 [记忆系统](记忆.md)。

### 4. team.runtime 配置段（分布式 Team）

| 路径 | 说明 |
|------|------|
| `team.runtime.mode` | 运行模式：`local` \| `distributed` |
| `team.runtime.role` | 进程角色：`leader` \| `teammate` |
| `team.runtime.member_name` | teammate 名称标识 |
| `team.teammate_mode` | teammate 构建方式：`build_mode` |
| `team.spawn_mode` | teammate 进程模式：`inprocess` |

详见 [分布式 Team](分布式Team.md)。

### 5. task_memory 配置段（经验记忆）

| 路径 | 说明 |
|------|------|
| `task_memory.enabled` | 是否启用经验记忆工具，默认 `true` |
| `task_memory.llm_model` | 经验记忆使用的 LLM 模型（留空则用主模型） |
| `task_memory.embedding_model` | 经验记忆使用的 Embedding 模型 |
| `task_memory.api_key` | 经验记忆 API 密钥（留空则用主密钥） |
| `task_memory.api_base` | 经验记忆 API 地址（留空则用主地址） |

启用后 Agent 将获得 `experience_retrieve`、`experience_learn`、`experience_clear` 三个工具。检索算法可选 `ACE`、`ReasoningBank`、`ReMe`。

### 6. email_settings 配置段（邮件）

| 路径 | 说明 |
|------|------|
| `email_settings.email_address` | 发件邮箱地址 |
| `email_settings.token` | 邮箱授权码 |
| `email_settings.smtp_server` | SMTP 服务器，默认 `smtp.gmail.com` |
| `email_settings.port` | SMTP 端口，默认 `587` |

### 7. extensions 配置段（扩展包）

| 路径 | 说明 |
|------|------|
| `extensions.extension_dirs` | 扩展包搜索目录，分号分隔（如 `E:/a;D:/b`），对应环境变量 `EXTENSION_DIRS` |

### 8. mcp 配置段（MCP 服务）

| 路径 | 说明 |
|------|------|
| `mcp.servers` | MCP 服务列表，每项含 `name`、`enabled`、`transport`（`stdio`/`sse`/`streamable-http`）、`command`、`args`、`url` 等 |

浏览器 MCP 运行时通过环境变量配置（见下方）。

### 9. updater 配置段（自动更新）

| 路径 | 说明 |
|------|------|
| `updater.enabled` | 是否启用自动更新，默认 `true` |
| `updater.repo_owner` | GitHub 仓库 owner |
| `updater.repo_name` | GitHub 仓库名 |
| `updater.asset_name_pattern` | 资源文件名模式 |
| `updater.timeout_seconds` | 更新检查超时，默认 `20` |

### 10. gateway 配置段（网关路由）

| 键 | 类型 | 默认值 | 说明 |
|---|------|--------|------|
| `gateway.session_map_scope` | string | `per_chat_bot` | SessionMap 作用域：`per_chat_bot`（同 chat+bot 共享会话）或 `per_chat_bot_user`（按 user 分会话）。仅企业场景使用，如飞书企业版等通道。 |

### 11. logging 配置段（日志）

| 键 | 类型 | 默认值 | 说明 |
|---|------|--------|------|
| `logging.level` | string | `INFO` | 全局日志级别 |
| `logging.console_level` | string | `INFO` | 控制台日志级别 |
| `logging.gateway` | string | `INFO` | Gateway 模块日志级别 |

日志文件存放在 `~/.jiuwenclaw/agent/.logs/` 下，按 `gateway.log`、`channel.log`、`agent_server.log` 分流；`full.log` 为汇总。

### 12. telemetry 配置段（OpenTelemetry 遥测）

| 键 | 类型 | 默认值 | 说明 |
|---|------|--------|------|
| `telemetry.enabled` | bool | `false` | 总开关（环境变量 `OTEL_ENABLED` 优先） |
| `telemetry.exporter` | string | `otlp` | 导出器类型：`otlp` / `console` / `none` |
| `telemetry.endpoint` | string | `http://localhost:4317` | OTLP endpoint |
| `telemetry.protocol` | string | `grpc` | 传输协议：`grpc` / `http` |
| `telemetry.headers` | map | `{}` | 公共 OTLP headers，可被 traces/metrics 覆盖 |
| `telemetry.log_messages` | bool | `true` | 是否在 span event 中记录完整消息内容 |
| `telemetry.service_name` | string | `jiuwenclaw` | 服务名称标识 |
| `telemetry.provider_factory` | string | | 自定义 Provider Factory，格式 `module:function` |
| `telemetry.traces.exporter` | string | | Trace 导出器，留空回退到 `telemetry.exporter` |
| `telemetry.traces.endpoint` | string | | Trace endpoint，留空回退到 `telemetry.endpoint` |
| `telemetry.traces.protocol` | string | | Trace 协议，留空回退到 `telemetry.protocol` |
| `telemetry.traces.headers` | map | `{}` | Trace 专用 headers |
| `telemetry.metrics.exporter` | string | | Metrics 导出器，留空回退到 `telemetry.exporter` |
| `telemetry.metrics.endpoint` | string | | Metrics endpoint，留空回退到 `telemetry.endpoint` |
| `telemetry.metrics.protocol` | string | | Metrics 协议，留空回退到 `telemetry.protocol` |

### 15. 配置优先级

- **环境变量** > **config.yaml**
- 例如：`config.yaml` 中 `react.model_name: ${MODEL_NAME:-deepseek-chat}` 会先读 `MODEL_NAME` 环境变量，无则用默认值 `deepseek-chat`。
- 前端 ConfigPanel 保存的项会写入 `.env`，下次启动时优先加载。
