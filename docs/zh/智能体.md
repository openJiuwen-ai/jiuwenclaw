# 智能体

`workspace` 是 JiuwenAvatar 的运行时工作目录，存放 Agent 的记忆、技能、会话数据及用户可配置的心跳任务。首次运行时（通过 `init` 或 `app`），`jiuwenavatar/resources/agent/workspace/` 下的基础模板会被复制到用户工作区 `~/.jiuwenavatar/agent/workspace/`。

内置技能不放在工作区模板里。随仓库分发的默认 Skill 源码位于 `jiuwenavatar/resources/avatar-skills/`；创建分身或安装 Persona 绑定技能时，再从这里安装到用户工作区。

## 目录结构总览

**用户 workspace**（`~/.jiuwenavatar/agent/workspace/`）：

```
workspace/
├── agent-data.json        # Agent 列表元数据（由 scripts/generate-agent-folders.js 动态生成）
├── AGENT.md               # Agent 身份描述（init 时从 AGENT_ZH.md 或 AGENT_EN.md 复制）
├── HEARTBEAT.md           # 心跳任务模板（init 时从 HEARTBEAT_ZH/EN.md 复制）
├── IDENTITY.md            # 身份描述（init 时从 IDENTITY_ZH/EN.md 复制）
├── SOUL.md                # Agent 灵魂/人格描述（init 时从 SOUL_ZH/EN.md 复制）
├── USER.md                # 用户身份信息模板
├── memory/                # 记忆系统
│   ├── MEMORY.md          # 长期记忆（init 时从 MEMORY_ZH/EN.md 复制）
│   ├── YYYY-MM-DD.md      # 按日期的当日记忆（动态生成）
│   ├── messages.json      # 消息压缩存储（动态生成）
│   └── memory.db          # ChromaDB 向量数据库（动态生成）
├── skills/                # 市场/安装的技能，以及 skills_state.json
│   ├── skills_state.json  # Skill 安装/市场状态（init 时从 resources/skills_state.json 复制）
│   ├── _marketplace/      # 市场仓库克隆目录
│   └── <skill-name>/      # 各技能目录
├── todo/                  # 待办数据（动态生成）
├── messages/              # 消息数据（动态生成）
├── agents/                # Agent 相关数据（动态生成）
└── session/               # 会话目录（动态生成）
    ├── sess_<id>/         # 普通会话
    └── heartbeat_<id>/    # 心跳任务会话
```

## 包内资源目录分工

| 路径 | 作用 | 是否纳入版本库 |
|------|------|----------------|
| `jiuwenavatar/resources/agent/workspace/*.md` | 初始化用户工作区的 AGENT、HEARTBEAT、IDENTITY、SOUL、USER 模板 | 是 |
| `jiuwenavatar/resources/agent/workspace/memory/*.md` | 初始化用户工作区的 MEMORY 模板 | 是 |
| `jiuwenavatar/resources/avatar-skills/` | 分身预置内置 Skill 源码，Persona 绑定技能从这里安装 | 是 |
| `jiuwenavatar/resources/skills_state.json` | 初始化技能状态模板，复制到用户 `skills/skills_state.json` | 是 |
| `jiuwenavatar/resources/agent/workspace/skills/` | 历史兼容/开发生成路径，不是当前权威内置技能目录 | 否 |
| `jiuwenavatar/resources/agent/workspace/agent-data.json` | 前端文件树索引，由脚本生成 | 否 |

运行时 `get_builtin_skills_dirs()` 会优先扫描 `resources/avatar-skills/`，然后兼容扫描 `resources/agent/workspace/skills/` 和旧版 `resources/agent/skills/`。

## 预置内容（Pre-configured）

随包或源码自带的、用户可直接使用或修改的内容：

| 路径（workspace 下） | 说明 |
|------|------|
| `HEARTBEAT.md` | 心跳任务模板（包内 `jiuwenavatar/resources/agent/workspace/HEARTBEAT_ZH.md` 或 `HEARTBEAT_EN.md`，初始化时按所选语言复制）。若存在且内容有效，Agent 会按心跳间隔读取并执行；否则仅返回 `HEARTBEAT_OK`。用户可在 Web 端编辑。 |
| `SOUL.md` | Agent 灵魂/人格描述，用于系统提示词。 |
| `skills/` | 市场/安装的技能。每个技能包含 `SKILL.md`、`prompts/`、`references/` 等。 |
| `skills/_marketplace/` | 技能市场仓库克隆目录。 |
| `memory/` | 记忆目录结构。`USER.md`、`memory/MEMORY.md` 可在首次使用时创建或由 init 模板复制。 |

---

## 动态生成内容（Dynamically Generated）

由系统或 Agent 在运行过程中创建和更新的内容：

| 路径（workspace 下） | 说明 |
|------|------|
| `agent-data.json` | 由 `scripts/generate-agent-folders.js` 生成，供 Web 端展示 Agent 列表。 |
| `skills/skills_state.json` | 由 `SkillManager` 维护，记录已安装的市场插件及状态。 |
| `memory/YYYY-MM-DD.md` | 按日期生成的当日记忆文件，Agent 通过 `write_memory` 等工具写入。 |
| `memory/messages.json` | 消息压缩存储，用于记忆系统。 |
| `memory/memory.db` | 向量检索数据库（ChromaDB），用于 `memory_search`。 |
| `skills/<skill>/evolutions.json` | 技能演化记录，由技能优化流程生成。 |
| `session/<session_id>/` | 每个会话对应一个子目录。 |
| `session/<session_id>/*` | 会话中 Agent 生成的其他文件（如查询结果、解析数据等）。 |

---

## 相关配置

- **Skill 根目录**：`config/config.yaml` 中 `skill_base_dir` 默认为 `agent/skills`。
- **Agent 工作区**：`~/.jiuwenavatar/agent/workspace/`（`get_agent_workspace_dir()`）。
- **会话目录**：`~/.jiuwenavatar/agent/sessions/`。
- **SkillNet 与技能在 Claw 中的使用方式**：详见 [技能.md](技能.md#5-skillnet-安装的技能在-claw-中如何被使用)。
