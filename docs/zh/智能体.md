# 智能体

`workspace` 是 JiuwenSwarm 的运行时工作目录，存放 Agent 的记忆、技能、会话数据及用户可配置的心跳任务。首次运行时（通过 `init` 或 `app`），`jiuwenswarm/resources/agent/` 下的模板会被复制到 `~/.jiuwenswarm/agent/jiuwenswarm_workspace/`。内置技能位于包内的 `jiuwenswarm/resources/agent/jiuwenswarm_workspace/skills/`；市场/安装的技能存储在用户 workspace 下。

![Workspace](../assets/images/agent.png)

## 目录结构总览

**用户 workspace**（`~/.jiuwenswarm/agent/workspace/`）：

```
workspace/
├── agent-data.json        # Agent 列表元数据（由 scripts/generate-agent-folders.js 动态生成）
├── skills_state.json      # Skill 安装/市场状态（动态生成）
├── AGENT.md               # Agent 身份描述（init 时从 AGENT_ZH.md 或 AGENT_EN.md 复制）
├── HEARTBEAT.md          # 心跳任务模板（init 时从 HEARTBEAT_ZH/EN.md 复制）
├── IDENTITY.md           # 身份描述（init 时从 IDENTITY_ZH/EN.md 复制）
├── SOUL.md               # Agent 灵魂/人格描述（init 时从 SOUL_ZH/EN.md 复制）
├── USER.md               # 用户身份信息（用户/Agent 创建）
├── MEMORY.md             # 长期记忆（init 时从 MEMORY_ZH/EN.md 复制）
├── memory/               # 记忆系统
│   ├── YYYY-MM-DD.md     # 按日期的当日记忆（动态生成）
│   ├── messages.json     # 消息压缩存储（动态生成）
│   └── memory.db          # ChromaDB 向量数据库（动态生成）
├── skills/               # 市场/安装的技能
│   ├── _marketplace/     # 市场仓库克隆目录（预置空目录）
│   └── <skill-name>/     # 各技能目录
└── session/              # 会话目录（动态生成）
    ├── sess_<id>/         # 普通会话
    │   ├── todo.md        # 待办列表（TodoToolkit 创建）
    │   └── *.md, *.json   # 会话中生成的文件
    └── heartbeat_<id>/    # 心跳任务会话
```

内置技能模板位于 `jiuwenswarm/resources/agent/jiuwenswarm_workspace/skills/`。这些内置技能不会在 init 时复制到用户 workspace（源码模式下直接从包内加载）。

## 预置内容（Pre-configured）

随包或源码自带的、用户可直接使用或修改的内容：

| 路径（workspace 下） | 说明 |
|------|------|
| `HEARTBEAT.md` | 心跳任务模板（包内 `jiuwenswarm/resources/agent/jiuwenswarm_workspace/HEARTBEAT_ZH.md` 或 `HEARTBEAT_EN.md`，初始化时按所选语言复制）。若存在且内容有效，Agent 会按心跳间隔读取并执行；否则仅返回 `HEARTBEAT_OK`。用户可在 Web 端编辑。 |
| `SOUL.md` | Agent 灵魂/人格描述，用于系统提示词。 |
| `skills/` | 市场/安装的技能。每个技能包含 `SKILL.md`、`prompts/`、`references/` 等。 |
| `skills/_marketplace/` | 技能市场仓库克隆目录，预置为空。 |
| `memory/` | 记忆目录结构。`USER.md`、`MEMORY.md` 可在首次使用时创建。 |

---

## 动态生成内容（Dynamically Generated）

由系统或 Agent 在运行过程中创建和更新的内容：

| 路径（workspace 下） | 说明 |
|------|------|
| `agent-data.json` | 由 `scripts/generate-agent-folders.js` 生成，供 Web 端展示 Agent 列表。 |
| `skills_state.json` | 由 `SkillManager` 维护，记录已安装的市场插件及状态。 |
| `memory/YYYY-MM-DD.md` | 按日期生成的当日记忆文件，Agent 通过 `write_memory` 等工具写入。 |
| `memory/messages.json` | 消息压缩存储，用于记忆系统。 |
| `memory/memory.db` | 向量检索数据库（ChromaDB），用于 `memory_search`。 |
| `skills/<skill>/evolutions.json` | 技能演化记录，由技能优化流程生成。 |
| `session/<session_id>/` | 每个会话对应一个子目录。 |
| `session/<session_id>/todo.md` | 由 `TodoToolkit` 创建，存储该会话的待办列表。 |
| `session/<session_id>/*` | 会话中 Agent 生成的其他文件（如查询结果、解析数据等）。 |

---

## 相关配置

- **Skill 根目录**：`config/config.yaml` 中 `skill_base_dir` 默认为 `agent/skills`。
- **记忆工作目录**：`~/.jiuwenswarm/agent/jiuwenswarm_workspace/`（`get_agent_workspace_dir()`）。
- **会话目录**：`~/.jiuwenswarm/agent/jiuwenswarm_workspace/session/`，每个 `session_id` 对应一个子目录。
- **SkillNet 与技能在 Claw 中的使用方式**：详见 [技能.md](技能.md#5-skillnet-安装的技能在-claw-中如何被使用)。
