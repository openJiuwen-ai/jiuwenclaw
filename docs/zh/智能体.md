# 智能体

`workspace` 是 JiuwenSwarm 的运行时工作目录，存放 Agent 的记忆、技能、会话数据及用户可配置的心跳任务。首次运行时（通过 `init` 或 `app`），`jiuwenswarm/resources/agent/workspace/` 下的模板会被复制到 `~/.jiuwenswarm/agent/workspace/`。内置技能位于包内的 `jiuwenswarm/resources/agent/workspace/skills/`；市场/安装的技能存储在用户 workspace 下。

## 目录结构总览

**用户 workspace**（`~/.jiuwenswarm/`）的完整运行时布局：

```
~/.jiuwenswarm/
├── .updates/             # 更新状态（动态生成）
│   └── web_process.json
├── agent/
│   ├── .checkpoint/      # 检查点数据库（运行时创建）
│   │   ├── checkpoint.db       # SQLite 检查点
│   │   ├── checkpoint.db-shm   # SQLite 共享内存
│   │   └── checkpoint.db-wal   # SQLite WAL 日志
│   ├── .logs/            # Agent 进程日志
│   │   ├── agent_server.log
│   │   ├── channel.log
│   │   ├── full.log
│   │   ├── gateway.log
│   │   ├── permissions.log
│   │   └── ws-dev.log
│   ├── sessions/         # 会话目录（动态生成）
│   │   ├── sess_<id>/    # 普通会话
│   │   │   ├── history.json  # 会话历史
│   │   │   ├── metadata.json # 会话元数据
│   │   │   └── *.md, *.json  # 会话中生成的文件
│   │   └── heartbeat_<id>/   # 心跳任务会话
│   └── workspace/        # Agent 标准工作空间
│       ├── agents/            # Agent 工作区（DeepAgent 标准节点）
│       │   └── .workspace     # 节点标记文件
│       ├── coding_memory/     # 编码记忆
│       │   ├── .workspace
│       │   └── MEMORY.md
│       ├── context/           # 会话上下文
│       │   ├── .workspace
│       │   └── session_memory.md
│       ├── memory/            # 记忆系统
│       │   ├── .workspace
│       │   ├── MEMORY.md      # 长期记忆（init 时从 MEMORY_ZH/EN.md 复制）
│       │   ├── daily_memory/  # 按日期的记忆文件（运行时创建）
│       │   │   ├── .workspace
│       │   │   ├── YYYY-MM-DD.md
│       │   │   └── ...
│       │   ├── memory.db      # ChromaDB 向量数据库（运行时创建）
│       │   ├── memory.db-shm
│       │   └── memory.db-wal
│       ├── messages/          # 消息工作区（DeepAgent 标准节点）
│       │   └── .workspace
│       ├── skills/            # 市场/安装的技能
│       │   ├── .workspace
│       │   ├── skills_state.json  # Skill 安装/市场状态（动态生成）
│       │   ├── _marketplace/      # 市场仓库克隆目录（运行时创建）
│       │   └── <skill-name>/
│       │       └── evolutions.json
│       ├── todo/              # 待办工作区（DeepAgent 标准节点）
│       │   └── .workspace
│       ├── extensions/        # 扩展插件（运行时创建）
│       ├── interactions/      # 交互上下文（运行时创建）
│       ├── agent-data.json    # Agent 列表元数据
│       ├── AGENT.md           # Agent 身份描述
│       ├── HEARTBEAT.md       # 心跳任务模板
│       ├── IDENTITY.md        # 身份描述
│       ├── SOUL.md            # Agent 灵魂/人格描述
│       └── USER.md            # 用户身份信息
├── auto-harness/         # 自动 CI 流程（动态生成）
│   └── config.yaml
├── config/               # 配置目录
│   ├── config.yaml       # 主配置文件
│   ├── .env              # 环境变量
│   ├── builtin_rules.yaml # 内置 shell 安全规则
│   └── runtime_state.yaml # 运行时状态（动态生成）
└── logs/                 # 业务日志
    └── logs/
        ├── llm.log           # LLM 调用日志
        ├── memory.log        # 记忆模块日志
        ├── runner.log        # Runner 日志
        ├── session.log       # 会话日志
        ├── sys_operation.log # 系统操作日志
        ├── interface/
        │   ├── jiuwen_interface.log
        │   └── jiuwen_prompt_builder_interface.log
        ├── performance/
        │   └── jiuwen_performance.log
        └── run/
            └── jiuwen.log
```

内置技能模板位于 `jiuwenswarm/resources/agent/workspace/skills/`。这些内置技能不会在 init 时复制到用户 workspace（源码模式下直接从包内加载）。

## 预置内容（Pre-configured）

随包或源码自带的、用户可直接使用或修改的内容：

| 路径（workspace 下） | 说明 |
|------|------|
| `AGENT.md` | Agent 身份描述。从 `AGENT_ZH.md`/`AGENT_EN.md` 按语言复制。 |
| `IDENTITY.md` | 身份描述。从 `IDENTITY_ZH.md`/`IDENTITY_EN.md` 按语言复制。 |
| `SOUL.md` | Agent 灵魂/人格描述，用于系统提示词。从 `SOUL_ZH.md`/`SOUL_EN.md` 按语言复制。 |
| `USER.md` | 用户身份信息。init 时从模板复制。 |
| `HEARTBEAT.md` | 心跳任务模板（包内 `jiuwenswarm/resources/agent/workspace/HEARTBEAT_ZH.md` 或 `HEARTBEAT_EN.md`，初始化时按所选语言复制）。若存在且内容有效，Agent 会按心跳间隔读取并执行；否则仅返回 `HEARTBEAT_OK`。用户可在 Web 端编辑。 |
| `skills/` | 市场/安装的技能。每个技能包含 `SKILL.md`、`prompts/`、`references/` 等。 |
| `skills/_marketplace/` | 技能市场仓库克隆目录，预置为空。 |
| `memory/` | 记忆目录结构。`MEMORY.md` 在 init 时从模板复制。 |

## 动态生成内容（Dynamically Generated）

由系统或 Agent 在运行过程中创建和更新的内容：

| 路径 | 说明 |
|------|------|
| `agent/.checkpoint/checkpoint.db` | SQLite 检查点数据库（附带 `.db-shm`、`.db-wal`）。 |
| `agent/.logs/*.log` | Agent 进程日志（gateway、agent_server、channel、full、permissions、ws-dev）。 |
| `agent/sessions/<session_id>/` | 每个会话对应一个子目录，内含 `history.json`（会话历史）、`metadata.json`（会话元数据）及会话中生成的 `*.md`、`*.json` 文件。 |
| `agent/sessions/<session_id>/todo.md` | 由 `TodoToolkit` 创建，存储该会话的待办列表（可选）。 |
| `agent/workspace/agent-data.json` | 由 `scripts/generate-agent-folders.js` 生成，供 Web 端展示 Agent 列表。 |
| `agent/workspace/coding_memory/MEMORY.md` | 编码记忆内容。 |
| `agent/workspace/context/session_memory.md` | 会话上下文记忆。 |
| `agent/workspace/memory/daily_memory/YYYY-MM-DD.md` | 按日期生成的当日记忆文件，Agent 通过 `write_memory` 等工具写入。 |
| `agent/workspace/memory/memory.db` | 向量检索数据库（ChromaDB），用于 `memory_search`（附带 `.db-shm`、`.db-wal`）。 |
| `agent/workspace/skills/skills_state.json` | 由 `SkillManager` 维护，记录已安装的市场插件及状态。 |
| `agent/workspace/skills/<skill>/evolutions.json` | 技能演化记录，由技能优化流程生成。 |
| `agent/workspace/skills/_marketplace/` | 技能市场仓库克隆目录（运行 `_sync_marketplace_repos` 时创建）。 |
| `agent/workspace/extensions/` | 扩展插件目录（运行时按需创建）。 |
| `agent/workspace/interactions/` | 交互上下文目录（运行时按需创建）。 |
| `.updates/web_process.json` | Web 进程更新状态。 |
| `auto-harness/config.yaml` | 自动 CI 流程配置。 |
| `config/runtime_state.yaml` | 运行时状态。 |
| `logs/logs/*.log` | 业务日志（llm、memory、runner、session、sys_operation）。 |
| `logs/logs/interface/jiuwen_interface.log` | Interface 模块日志。 |
| `logs/logs/interface/jiuwen_prompt_builder_interface.log` | Prompt builder 接口日志。 |
| `logs/logs/performance/jiuwen_performance.log` | 性能日志。 |
| `logs/logs/run/jiuwen.log` | 运行日志。 |

## 相关配置

- **Skill 根目录**：`config/config.yaml` 中 `skill_base_dir` 默认为 `agent/skills`。
- **Agent 工作空间**：`~/.jiuwenswarm/agent/workspace/`（`get_agent_workspace_dir()`）。
- **会话目录**：`~/.jiuwenswarm/agent/sessions/`，每个 `session_id` 对应一个子目录。
- **SkillNet 与技能在 Swarm 中的使用方式**：详见 [技能.md](技能.md#5-skillnet-安装的技能在-swarm-中如何被使用)。
