# 智能体

`workspace` 是 JiuwenClaw 的运行时工作目录，存放 Agent 的记忆、技能、会话数据及用户可配置的心跳任务。在**源码模式**下使用项目根目录的 `workspace`；在**包安装模式**（whl）下，首次运行会将包内预置的 `workspace` 复制到 `~/.jiuwenclaw/workspace`。

![Workspace](../assets/images/agent.png)

## 目录结构总览

```
workspace/
├── agent-data.json        # Agent 列表元数据（动态生成）
├── skills_state.json      # Skill 安装/市场状态（动态生成）
├── agent/                 # Agent 工作区
│   ├── home/              # 用户可编辑主页配置（init 时从包内模板按语言复制）
│   │   ├── HEARTBEAT.md   # 心跳任务（来自 HEARTBEAT_ZH/EN.md）
│   │   ├── PRINCIPLE.md   # 原则（来自 PRINCIPLE_ZH/EN.md）
│   │   └── TONE.md        # 语气（来自 TONE_ZH/EN.md）
│   ├── memory/            # 记忆系统
│   │   ├── USER.md        # 用户身份信息（用户/Agent 创建）
│   │   ├── MEMORY.md      # 长期记忆（用户/Agent 创建）
│   │   ├── YYYY-MM-DD.md  # 按日期的当日记忆（动态生成）
│   │   ├── messages.json  # 消息压缩存储（动态生成）
│   │   └── memory.db      # 向量检索数据库（动态生成）
│   ├── skills/            # 技能目录
│   │   ├── _marketplace/  # 市场仓库克隆目录（预置空目录）
│   │   └── <skill-name>/  # 各技能（预置 + 市场安装）
│   └── SOUL.md            # Agent 灵魂/人格描述（预置）
└── session/               # 会话工作目录（动态生成）
    ├── sess_<id>/         # 普通会话
    │   ├── todo.md        # 待办列表（TodoToolkit 创建）
    │   └── *.md, *.json   # 会话中生成的文件
    └── heartbeat_<id>/    # 心跳任务会话
```

---

## 预置内容（Pre-configured）

随包或源码自带的、用户可直接使用或修改的内容：

| 路径 | 说明 |
|------|------|
| `agent/home/HEARTBEAT.md` | 心跳任务模板（包内 `resources/agent/HEARTBEAT_ZH.md` 或 `HEARTBEAT_EN.md`，初始化时按所选语言复制）。若存在且内容有效，Agent 会按心跳间隔读取并执行；否则仅返回 `HEARTBEAT_OK`。用户可在 Web 端编辑。 |
| `agent/SOUL.md` | Agent 灵魂/人格描述，用于系统提示词。 |
| `agent/skills/` | 内置技能目录。每个技能包含 `SKILL.md`、`prompts/`、`references/` 等。 |
| `agent/skills/_marketplace/` | 技能市场仓库克隆目录，预置为空，用于存放从市场安装的插件。 |
| `agent/memory/` | 记忆目录结构。`USER.md`、`MEMORY.md` 可由用户或 Agent 首次创建。 |

## 动态生成内容（Dynamically Generated）

由系统或 Agent 在运行过程中创建和更新的内容：

| 路径 | 说明 |
|------|------|
| `agent-data.json` | 由 `scripts/generate-agent-folders.js` 生成，供 Web 端展示 Agent 列表。 |
| `skills_state.json` | 由 `SkillManager` 维护，记录已安装的市场插件及状态。 |
| `agent/memory/YYYY-MM-DD.md` | 按日期生成的当日记忆文件，Agent 通过 `write_memory` 等工具写入。 |
| `agent/memory/messages.json` | 消息压缩存储，用于记忆系统。 |
| `agent/memory/memory.db` | 向量检索数据库（ChromaDB），用于 `memory_search`。 |
| `agent/skills/<skill>/evolutions.json` | 技能演化记录，由技能优化流程生成。 |
| `session/<session_id>/` | 每个会话对应一个子目录，由 `app.py` 创建。 |
| `session/<session_id>/todo.md` | 由 `TodoToolkit` 创建，存储该会话的待办列表。 |
| `session/<session_id>/*` | 会话中 Agent 生成的其他文件（如查询结果、解析数据等）。 |

## 相关配置

- **Skill 根目录**：`config/config.yaml` 中 `skill_base_dir` 默认为 `workspace/agent/skills`。
- **记忆工作目录**：`workspace/agent`（即 `get_agent_workspace_dir()`）。
- **会话目录**：`workspace/session`，每个 `session_id` 对应一个子目录。
- **SkillNet 与技能在 Claw 中的使用方式**：详见 [技能.md](技能.md#5-skillnet-安装的技能在-claw-中如何被使用)。

## 文件处理

### 文件输入输出隔离

AgentServer 实现了统一的文件输入输出隔离机制，确保不同用户、不同会话的文件完全隔离。

#### 目录结构

每个会话创建独立的输入输出目录：

```
对话模式（未指定 workspace_dir）：
  workspace/files/{user_id}/{chat_id}/input/   # 输入文件目录
  workspace/files/{user_id}/{chat_id}/output/  # 输出文件目录

项目模式（指定了 workspace_dir）：
  {project_dir}/files/{user_id}/{chat_id}/input/   # 输入文件目录
  {project_dir}/files/{user_id}/{chat_id}/output/  # 输出文件目录
```

**路径说明**：
- `{user_id}`：用户 ID（从 request.metadata.user_id 获取）
- `{chat_id}`：会话 ID（经过安全清理，移除特殊字符和路径分隔符）
- `input/`：存放前端上传的输入文件
- `output/`：存放 Agent 生成的输出文件

#### 运行模式

**对话模式**（默认）：
- 用户未指定 `workspace_dir`
- `effective_project_dir` = workspace（默认工作目录）
- 输入输出目录位于 workspace/files/ 下
- Agent 在默认 workspace 工作，所有文件统一隔离管理

**项目模式**：
- 用户指定了 `workspace_dir`（项目目录）
- `effective_project_dir` = 用户指定的 project_dir
- Agent 可以访问和编辑项目文件
- 输入输出目录位于项目目录的 files/ 子目录下
- Agent 生成的文件应保存到 output/ 目录，便于管理和清理

#### Agent 工作目录与输出目录

**关键概念**：
- **effective_project_dir**：Agent 的当前工作目录 (cwd)，也是权限边界
  - 对话模式下为 workspace
  - 项目模式下为用户指定的项目目录
  - Agent 可以在此目录访问和编辑文件

- **output_dir**：Agent 输出文件的专用目录
  - 位于 `{base}/files/{user_id}/{chat_id}/output/`
  - 通过 ContextVar API `get_effective_request_output_dir()` 获取
  - Agent 应将生成的输出文件保存到此目录

**推荐实践**：
- Agent 在 effective_project_dir 工作（编辑项目文件、访问代码等）
- 最终输出文件保存到 runtime_config["output_dir"]
- 使用 send_file_to_user 工具发送 output_dir 中的文件给用户

### Agent访问文件

Agent通过 `inputs["files"]` 访问前端上传的文件。AgentServer在调用Agent前，会自动下载文件到本地 input_dir 并更新文件信息为本地路径。

#### 文件格式

前端发送的文件可以是两种格式：

**字典格式**（键值对）：
```python
files = {
    "document": {
        "path": "/workspace/session/sess_123/downloaded_document.pdf",
        "name": "document.pdf",
        "uri": "file:///data/storage/files/user1/web_chat1/20260515_120000/document.pdf"
    },
    "image": {
        "path": "/workspace/session/sess_123/downloaded_image.jpg",
        "name": "image.jpg",
        "uri": "file:///data/storage/files/user1/web_chat1/20260515_120000/image.jpg"
    }
}
```

**列表格式**：
```python
files = [
    {
        "path": "/workspace/session/sess_123/downloaded_document.pdf",
        "name": "document.pdf",
        "uri": "file:///data/storage/files/user1/web_chat1/20260515_120000/document.pdf"
    },
    {
        "path": "/workspace/session/sess_123/downloaded_image.jpg",
        "name": "image.jpg",
        "uri": "file:///data/storage/files/user1/web_chat1/20260515_120000/image.jpg"
    }
]
```

#### Agent代码示例

```python
from pathlib import Path

async def process_message_impl(request, inputs):
    """处理消息"""

    # 获取 output_dir（推荐输出位置）
    # 通过 ContextVar API 获取当前请求的 output_dir
    from jiuwenclaw.agentserver.tools.subagent_executor.context_vars import get_effective_request_output_dir
    output_dir_path = get_effective_request_output_dir()
    output_dir = Path(output_dir_path) if output_dir_path else Path("/tmp/output")
    output_dir.mkdir(parents=True, exist_ok=True)

    # 获取文件列表
    files = inputs.get("files", [])

    # 处理字典格式
    if isinstance(files, dict):
        for file_key, file_ref in files.items():
            path = file_ref.get("path")
            if path and Path(path).exists():
                # 读取文件内容
                content = Path(path).read_text()
                # 处理文件...
                print(f"处理文件 {file_key}: {file_ref.get('name')}")

    # 处理列表格式
    elif isinstance(files, list):
        for file_ref in files:
            path = file_ref.get("path")
            if path and Path(path).exists():
                # 读取文件内容
                content = Path(path).read_text()
                # 处理文件...
                print(f"处理文件: {file_ref.get('name')}")

    # 生成输出文件（保存到 output_dir）
    result_file = output_dir / "result.txt"
    result_file.write_text("处理结果内容")
```

### Agent返回文件

Agent可以通过 `payload.files` 返回生成的文件给前端。AgentServer会自动从文件路径读取文件并上传到对象存储。

#### 推荐输出文件位置

Agent 应将生成的输出文件保存到 `get_effective_request_output_dir()` 获取的目录：
- 该目录已由 AgentServer 自动创建
- 路径格式：`{base}/files/{user_id}/{chat_id}/output/`
- 文件隔离，便于管理和清理
- send_file_to_user 工具会优先引导使用此目录

获取方式：
```python
from jiuwenclaw.agentserver.tools.subagent_executor.context_vars import get_effective_request_output_dir
output_dir = get_effective_request_output_dir()
```

#### 返回格式

使用统一结构 `{path, name, uri}`：

```python
from jiuwenclaw.agentserver.interface import AgentResponse
from pathlib import Path

async def process_message_impl(request, inputs):
    """处理消息并返回文件"""

    # 获取 output_dir
    from jiuwenclaw.agentserver.tools.subagent_executor.context_vars import get_effective_request_output_dir
    output_dir_path = get_effective_request_output_dir()
    output_dir = Path(output_dir_path) if output_dir_path else Path("/tmp/output")
    output_dir.mkdir(parents=True, exist_ok=True)

    # 生成输出文件（保存到 output_dir）
    output_file = output_dir / "result.txt"
    output_file.write_text("处理结果内容")

    # 返回响应
    return AgentResponse(
        request_id=request.request_id,
        channel_id=request.channel_id,
        ok=True,
        payload={
            "content": "处理完成",
            "files": [
                {
                    "path": str(output_file),     # 必填：本地文件路径（推荐使用 output_dir）
                    "name": "result.txt"          # 可选：文件名（缺失时自动补充）
                    # uri 字段由 AgentServer 自动添加
                }
            ]
        }
    )
```

#### AgentServer自动处理

AgentServer的 `upload_agent_files()` 方法会：

1. 检查文件是否存在
2. 自动补充缺失的 `name` 字段（使用Path(local_path).name）
3. 上传文件到对象存储
4. 添加 `uri` 字段

```python
# AgentServer处理后的响应
{
    "content": "处理完成",
    "files": [
        {
            "path": "/workspace/session/sess_123/result.txt",
            "name": "result.txt",
            "uri": "file:///data/storage/files/user1/web_chat1/20260515_150000/result.txt"
        }
    ]
}
```

### 文件处理最佳实践

1. **检查文件存在**：使用 `Path(path).exists()` 检查文件是否已下载到本地
2. **处理多种格式**：Agent应同时支持字典和列表格式的文件输入
3. **错误处理**：文件不存在时，记录日志并优雅处理，不要抛出异常阻断流程
4. **清理临时文件**：在会话结束后，建议清理生成的临时文件（AgentServer会自动上传并清理）

### 完整示例

```python
from pathlib import Path
from jiuwenclaw.agentserver.interface import AgentResponse
import logging

async def process_message_impl(request, inputs):
    """完整文件处理示例"""

    logger = logging.getLogger(__name__)

    # 1. 处理输入文件
    files = inputs.get("files", [])
    processed_content = []

    if isinstance(files, dict):
        for file_key, file_ref in files.items():
            path = file_ref.get("path")
            if path:
                if Path(path).exists():
                    content = Path(path).read_text()
                    processed_content.append(f"{file_key}: {content[:100]}...")
                else:
                    logger.warning(f"文件不存在: {path}")
    elif isinstance(files, list):
        for file_ref in files:
            path = file_ref.get("path")
            if path:
                if Path(path).exists():
                    content = Path(path).read_text()
                    processed_content.append(content[:100])
                else:
                    logger.warning(f"文件不存在: {path}")

    # 2. 生成输出文件
    output_file = Path(f"/tmp/{request.request_id}_output.txt")
    output_file.write_text(f"处理了 {len(processed_content)} 个文件")

    # 3. 返回响应
    return AgentResponse(
        request_id=request.request_id,
        channel_id=request.channel_id,
        ok=True,
        payload={
            "content": f"成功处理 {len(processed_content)} 个文件",
            "files": [
                {
                    "path": str(output_file),
                    "name": "output.txt"
                }
            ]
        }
    )
```
