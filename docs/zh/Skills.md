# 技能管理（Skills）

技能（Skill）是 JiuwenSwarm 中可复用的能力单元，可通过技能市场安装使用。

## 技能市场

- 在「技能广场」页面浏览、检索可用技能
- 支持按分类与关键词搜索

## 安装技能

1. 在技能广场找到目标技能
2. 点击安装
3. 安装完成后可在「我的技能」中查看

## 使用技能

- 安装后可在对话中按技能使用方式调用
- 部分技能需要额外配置，请阅读技能详情页说明

## 卸载技能

1. 在「我的技能」中找到要卸载的技能
2. 点击卸载
3. 如卸载后需重新安装，请确认卸载完成后再操作

## 技能源管理

- 支持添加/删除技能源（市场源）
- 技能源影响技能广场的可用技能列表

## 常见问题

### 重新安装同名技能提示冲突

- 确认已完整卸载旧技能
- 检查本地是否有残留配置，必要时清理后重装
- 反馈问题请附上 `~/.jiuwenswarm/logs/` 下的日志

### 安装的技能不生效

- 确认技能已出现在「我的技能」列表
- 重启服务后重试
