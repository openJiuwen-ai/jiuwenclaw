# 对象存储接口设计

## 概述

JiuwenClaw的对象存储接口是一个**AgentServer内部组件**，用于处理AgentServer与多种对象存储服务（华为云OBS、阿里云OSS、本地文件系统等）之间的文件交互。

### 核心定位

**重要说明**：
- ✅ **这是AgentServer的内部存储接口**，仅处理AgentServer与对象存储之间的文件上传下载
- ❌ **不涉及**Web客户端如何上传下载文件（由前端团队负责）
- ❌ **不提供**HTTP端点或直接连接到Web客户端
- ❌ **不改变**现有消息流（User → Channel → Gateway → AgentServer）

### 职责边界

```
┌─────────────────────────────────────────────────────────────┐
│                    职责边界划分                                 │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【前端团队负责】              【AgentServer存储接口】       │
│                                                             │
│  Web客户端上传文件到对象存储      从对象存储下载文件到        │
│  Web客户端从对象存储下载文件      本地workspace             │
│  管理对象存储连接和认证          上传本地文件到对象存储       │
│                                                             │
│  【现有系统】                  【不涉及】                     │
│  - 消息流：用户→Channel→Gateway→AgentServer                    │
│  - E2AEnvelope消息协议                                        │
│  - WebChannel的_process_files()                               │
│  - Gateway的FileTransferHandler                                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 核心功能

### 1. 文件下载流程（输入文件）

```
Web客户端（上传文件到对象存储，由前端团队负责）
         ↓
    通过WebSocket发送文件URI
         ↓
Gateway → AgentServer（收到E2AEnvelope.params.files）
         ↓
AgentServer存储接口（下载文件到本地workspace）
         ↓
Agent（使用本地文件路径）
```

**使用场景**：
- 用户上传图片、文档等文件给Agent分析
- 一次对话可以上传多个文件
- 支持所有文件类型

**详细流程**：

```

### 2. 文件上传流程（输出文件）

```

## 存储后端支持

| 存储后端 | 类型 | 适用场景 | 配置键 |
|---------|------|---------|--------|
| LocalStorage | 本地文件系统 | 开源版本、开发环境 | `local` |
| ObsStorage | 华为云OBS | 商用版本、生产环境 | `huawei_obs` |
| OssStorage | 阿里云OSS | 商用版本、生产环境 | `aliyun_oss` |
| CosStorage | 腾讯云COS | 商用版本、生产环境（可选） | `tencent_cos` |

## 文件隔离机制

### USER_ID 级别隔离

**设计原则**：仅使用 USER_ID 进行文件隔离，不使用 SESSION_ID 或 CHAT_ID。

**原因**：
- 历史消息中的对象存储URI已经包含了文件的唯一标识
- 即使session_id变化，旧会话中的文件URI仍然可访问
- 简化本地路径组织，避免session_id带来的复杂度

```
本地文件结构：
~/.jiuwenclaw/agent/jiuwenclaw_workspace/
└── files/
    └── {user_id}/          # 用户唯一标识
        ├── input/          # 输入文件（从对象存储下载）
        │   ├── image_001.jpg
        │   └── document.pdf
        └── output/         # 输出文件（Agent生成）
            ├── chart_001.png
            └── report.pdf

对象存储路径结构（由前端负责）：
bucket: jiuwenclaw-data
└── files/
    └── {user_id}/
        └── {YYYYMMDD_HHMMSS}/  # 上传时间戳
            └── filename.ext

示例URI：
https://obs.../files/alice/20250511_143052/image.jpg
                    ↑       ↑
                  user_id  时间戳
```

**优势**：
- 不同用户的文件完全隔离
- 简化本地文件管理
- 历史消息中的文件URI永久可访问
- 不依赖session_id或chat_id

## 核心接口

### StorageBackend 抽象接口

```python
# jiuwenclaw/storage/backend.py

from abc import ABC, abstractmethod

class StorageBackend(ABC):
    """
    对象存储后端抽象接口

    核心职责：
    1. download_file(): 从对象存储URI下载文件到本地workspace
    2. upload_file(): 上传本地文件到对象存储，返回URI

    设计原则：
    - 简单：只有两个核心方法
    - 内部：仅AgentServer内部使用
    - 无状态：不维护会话状态
    """

    @abstractmethod
    async def download_file(
        self,
        uri: str,           # 对象存储URI（来自E2AEnvelope.params.files）
        local_path: str,    # 本地保存路径（Agent workspace）
    ) -> None:
        """
        从对象存储下载文件到本地workspace

        支持的URI格式：
            - https://obs... (华为云OBS)
            - https://oss... (阿里云OSS)
            - http://... (本地存储服务)
            - file://... (本地文件系统)

        使用场景:
            AgentServer收到E2AEnvelope.params.files后，
            需要下载文件到workspace供Agent使用
        """
        pass

    @abstractmethod
    async def upload_file(
        self,
        local_path: str,    # Agent生成的本地文件
        user_id: str,       # 用户ID（用于路径隔离）
    ) -> str:              # 返回对象存储URI
        """
        上传本地文件到对象存储

        返回:
            对象存储URI（https://obs:// 或 https://oss://）

        使用场景:
            Agent生成文件后，需要上传到对象存储
            URI通过E2AResponse返回给前端
        """
        pass
```

### 工厂类

```python
# jiuwenclaw/storage/factory.py

class StorageService:
    """存储服务工厂类（单例）"""

    _instance = None

    @classmethod
    async def get_instance(cls) -> StorageBackend:
        """获取存储服务实例（单例）"""
        if cls._instance is None:
            cls._instance = await cls._create_backend()
        return cls._instance

    @classmethod
    async def _create_backend(cls) -> StorageBackend:
        """根据配置创建后端"""
        from jiuwenclaw.config import get_config

        config = get_config()["storage"]
        backend_type = config.get("type", "local")

        if backend_type == "local":
            from jiuwenclaw.storage.local_backend import LocalStorageBackend
            return LocalStorageBackend(config["local"])

        elif backend_type == "huawei-obs":
            from jiuwenclaw.storage.obs_backend import ObsStorageBackend
            return ObsStorageBackend(config["huawei_obs"])

        elif backend_type == "aliyun-oss":
            from jiuwenclaw.storage.oss_backend import OssStorageBackend
            return OssStorageBackend(config["aliyun_oss"])

        else:
            raise ValueError(f"Unknown storage type: {backend_type}")
```

## AgentServer集成

### 输入文件处理（下载）

```python
# jiuwenclaw/agentserver/interface.py

class JiuWenClaw:

    def __init__(self, ...):
        # 初始化存储服务
        from jiuwenclaw.storage import StorageService
        self._storage = StorageService.get_instance()

    async def _prepare_input_files(
        self,
        envelope: E2AEnvelope,
        workspace_dir: str,
    ):
        """
        预处理输入文件：从对象存储下载到本地workspace

        调用时机：process_message开始之前

        输入：envelope.params.files = [{uri: "https://obs.../img.jpg"}]
        输出：修改params，添加path字段
        """
        if "files" not in envelope.params:
            return

        user_id = envelope.user_id or "default"

        for file_info in envelope.params["files"]:
            uri = file_info.get("uri") or file_info.get("url")
            if not uri:
                continue

            # 构建本地路径（仅使用 user_id）
            filename = file_info.get("name", "unknown_file")
            local_path = self._build_local_path(
                workspace_dir, user_id, "input", filename
            )

            try:
                # 调用存储接口下载
                await self._storage.download_file(uri=uri, local_path=local_path)

                # 添加本地路径到file_info
                file_info["path"] = local_path

            except Exception as e:
                logger.error(f"Failed to download file {uri}: {e}")
                # 可选：移除失败的文件引用
```

### 输出文件处理（上传）

```python
# jiuwenclaw/agentserver/interface.py

class JiuWenClaw:

    async def _handle_output_files(
        self,
        response: AgentResponse,
        user_id: str,
    ):
        """
        后处理输出文件：上传到对象存储

        调用时机：process_message结束之前

        输入：response可能包含本地文件路径
        输出：修改response，添加uri字段
        """
        # 提取Agent生成的文件路径
        local_files = self._extract_generated_files(response)

        if not local_files:
            return

        uploaded_files = []

        for local_path in local_files:
            try:
                # 调用存储接口上传（仅使用 user_id）
                uri = await self._storage.upload_file(
                    local_path=local_path,
                    user_id=user_id
                )

                uploaded_files.append({
                    "path": local_path,
                    "uri": uri
                })

            except Exception as e:
                logger.error(f"Failed to upload file {local_path}: {e}")

        # 更新response
        if response.payload:
            response.payload["files"] = uploaded_files
```

### 完整示例：输入输出文件处理

```python
# AgentServer收到请求
envelope = E2AEnvelope(
    method="chat.send",
    params={
        'content': '请分析这张图片',
        'files': [{
            'uri': 'https://obs.../files/alice/20250511_143052/input/image.jpg',
            'name': 'image.jpg'
        }]
    },
    context={
        'user_id': 'alice'
    }
)

# 1. 输入文件处理（下载）
await self._prepare_input_files(envelope, workspace_dir)
# 结果：params.files[0]['path'] = '~/.jiuwenclaw/agent/jiuwenclaw_workspace/files/alice/input/image.jpg'

# 2. Agent处理（使用本地文件）
response = await self._agent.process(envelope.params)

# 3. 输出文件处理（上传）
if response.contains_files():
    await self._handle_output_files(response, 'alice')
    # 结果：response.files = [{'path': '...', 'uri': 'https://obs.../files/alice/20250511_143105/output/result.png'}]

# 4. 返回响应给Gateway，Gateway传递给Web客户端
return response
```

## 故障排查

### 常见问题

#### 1. 文件下载失败

**症状**: Agent无法访问上传的文件

**排查步骤**:
1. 检查文件URI是否正确
2. 检查文件是否存在
3. 查看AgentServer日志
4. 验证存储后端配置

#### 2. 文件上传失败

**症状**: Agent生成的文件无法返回给用户

**排查步骤**:
1. 检查本地文件路径
2. 检查存储后端权限
3. 检查文件大小限制
4. 查看AgentServer日志

#### 3. 签名URL无法访问

**症状**: Web客户端无法通过URL下载文件

**排查步骤**:
1. 检查URL是否过期
2. 检查bucket权限配置
3. 验证endpoint配置
4. 测试URL是否正确

## 性能优化建议

### 1. 并发控制

配置并发传输数量：

```yaml
storage:
  max_concurrent_transfers: 5  # 并发上传/下载数量
```

### 2. 文件大小限制

配置文件大小限制：

```yaml
storage:
  local:
    max_file_size: 104857600  # 100MB
  huawei_obs:
    max_file_size: 104857600
```

### 3. 超时设置

配置传输超时时间：

```yaml
storage:
  transfer_timeout: 300  # 5分钟
```

### 4. 大文件处理

对于大文件（>10MB）：
- 使用分块下载/上传
- 显示进度指示
- 支持断点续传

## 安全建议

### 1. 访问密钥管理

- ✅ 使用环境变量存储密钥
- ❌ 不要在配置文件中硬编码密钥
- ✅ 定期轮换密钥
- ✅ 使用最小权限原则

### 2. 网络安全

- ✅ 生产环境使用HTTPS
- ✅ 配置bucket策略限制访问
- ✅ 使用签名URL（临时访问）

### 3. 文件验证

- ✅ 验证文件类型
- ✅ 限制文件大小
- ✅ 扫描恶意文件

### 4. 访问控制

- 只处理属于该用户/会话的文件
- 验证URI的合法性
- 限制文件大小

### 迁移路径

```
阶段1：添加storage模块（可选）
├─ 配置storage.type=local
└─ 默认禁用，通过配置启用

阶段2：逐步集成到AgentServer
├─ 在process_message中调用存储接口
├─ 保持原有逻辑作为降级
└─ 逐步迁移

阶段3：商用版本启用OBS/OSS
├─ 配置storage.type=huawei-obs
└─ 完整功能
```
