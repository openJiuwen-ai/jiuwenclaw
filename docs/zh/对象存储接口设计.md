# 对象存储接口设计

## 概述

JiuwenClaw的对象存储接口是一个**AgentServer内部组件**，用于处理AgentServer与多种对象存储服务（华为云OBS、阿里云OSS、本地文件系统等）之间的文件交互。

### 核心定位

**重要说明**：
- ✅ **这是AgentServer的内部存储接口**，仅处理AgentServer与对象存储之间的文件上传下载
- ❌ **不涉及**Web客户端如何上传下载文件（由前端团队负责）
- ❌ **不提供**HTTP端点或直接连接到Web客户端
- ❌ **不改变**现有消息流（User → Channel → Gateway → AgentServer）

### 职责边界

```
┌─────────────────────────────────────────────────────────────┐
│                    职责边界划分                                 │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  【前端团队负责】              【AgentServer存储接口】       │
│                                                             │
│  Web客户端上传文件到对象存储      从对象存储下载文件到        │
│  Web客户端从对象存储下载文件      本地workspace             │
│  管理对象存储连接和认证          上传本地文件到对象存储       │
│                                                             │
│  【现有系统】                  【不涉及】                     │
│  - 消息流：用户→Channel→Gateway→AgentServer                    │
│  - E2AEnvelope消息协议                                        │
│  - WebChannel的_process_files()                               │
│  - Gateway的FileTransferHandler                                │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 核心功能

### 1. 文件下载流程（输入文件）

```
Web客户端（上传文件到对象存储，由前端团队负责）
         ↓
    通过WebSocket发送文件URI
         ↓
Gateway → AgentServer（收到E2AEnvelope.params.files）
         ↓
AgentServer存储接口（下载文件到本地workspace）
         ↓
Agent（使用本地文件路径）
```

**使用场景**：
- 用户上传图片、文档等文件给Agent分析
- 一次对话可以上传多个文件
- 支持所有文件类型

### 2. 文件上传流程（输出文件）

```

         ↓

         ↓
```

## 存储后端支持

| 存储后端 | 类型 | 适用场景 | 配置键 |
|---------|------|---------|--------|
| **LocalStorage** | 本地文件系统 | 开源版本、开发环境 | `local` |
| **ObsStorage** | 华为云OBS | 商用版本、生产环境 | `huawei_obs` |
| **OssStorage** | 阿里云OSS | 商用版本、生产环境 | `aliyun_oss` |
| **扩展支持** | AWS S3/Azure Blob/腾讯云COS等 | 商用版本、生产环境 | 自定义 |

### 核心抽象基类

系统提供 `BaseStorageBackend` 抽象基类，商用实现只需继承并实现核心方法：

```python
from abc import ABC, abstractmethod

class BaseStorageBackend(ABC):
    """
    🎯 简化的存储后端抽象基类 - 统一配置验证和客户端管理

    核心改进：
    1. 统一的配置验证（ak/sk 校验）
    2. 模板方法模式减少重复代码
    3. 懒加载客户端 + 连接测试
    4. 向后兼容现有实现
    """

    def __init__(self, config: dict):
        """统一初始化入口"""
        # 1. 配置验证
        self.config = self._validate_config(config)

        # 2. 基础属性设置
        self.access_key = self.config.get("access_key", "")
        self.secret_key = self.config.get("secret_key", "")
        self.bucket = self.config.get("bucket", "")
        self.endpoint = self.config.get("endpoint", "")
        self.region = self.config.get("region", "")

        # 3. 懒加载客户端
        self._client = None

        # 4. 日志
        self.logger = logging.getLogger(self.__class__.__name__)
        self.logger.info(f"{self.__class__.__name__} initialized: bucket={self.bucket}")

    def _validate_config(self, config: dict) -> dict:
        """🔒 基础配置验证模板方法 - 子类可重写"""
        if not isinstance(config, dict):
            raise ValueError("配置必须是字典类型")
        return config

    def _get_client(self):
        """🔧 客户端获取模板方法（懒加载）"""
        if self._client is None:
            self._client = self._create_client()
            self._test_connection()  # 可选连接测试
        return self._client

    @abstractmethod
    def _create_client(self):
        """🏗️ 客户端创建抽象方法 - 子类必须实现"""
        pass

    def _test_connection(self):
        """🔌 连接测试模板方法 - 子类可重写"""
        pass

    @abstractmethod
    async def upload_file(
        self,
        local_path: str,
        user_id: str,
        chat_id: str,
        channel_type: str
    ) -> str:
        """上传文件 - 返回URI"""
        pass

    @abstractmethod
    async def download_file(self, uri: str, local_path: str) -> None:
        """下载文件"""
        pass

    @abstractmethod
    async def delete_chat_files(
        self,
        user_id: str,
        chat_id: str,
        channel_type: str,
        older_than_hours: Optional[int] = None
    ) -> int:
        """删除会话文件 - 返回删除数量"""
        pass

    @abstractmethod
    async def delete_user_files(
        self,
        user_id: str,
        older_than_hours: int = 24
    ) -> int:
        """删除用户文件 - 返回删除数量"""
        pass
```

### 本地存储实现示例

```python
"""本地文件系统存储后端实现示例"""

import asyncio
import logging
import shutil
from pathlib import Path
from typing import Optional

from jiuwenclaw.storage.backend import BaseStorageBackend
from jiuwenclaw.storage.exceptions import DownloadError, UploadError
from jiuwenclaw.storage.utils import sanitize_chat_id, build_object_key

logger = logging.getLogger(__name__)


class LocalStorageBackend(BaseStorageBackend):
    """
    本地文件系统作为"对象存储"。

    实际上是通过HTTP从本地存储服务下载，
    或者直接访问本地文件系统（file://协议）。
    """

    def _validate_config(self, config: dict) -> dict:
        """本地存储特定配置验证"""
        super()._validate_config(config)

        if not config.get("base_dir"):
            raise ValueError("本地存储配置不完整，缺少: base_dir")

        return config

    def __init__(self, config: dict):
        """初始化本地存储后端"""
        super().__init__(config)
        self.base_dir = Path(self.config["base_dir"]).expanduser()
        self.base_dir.mkdir(parents=True, exist_ok=True)
        self.logger.info(f"LocalStorageBackend initialized with base_dir: {self.base_dir}")

    def _create_client(self):
        """本地存储不需要客户端"""
        return None  # 本地存储不需要客户端

    def _test_connection(self):
        """测试本地存储目录访问"""
        if not self.base_dir.exists():
            raise ValueError(f"本地存储目录不存在: {self.base_dir}")

    async def download_file(self, uri: str, local_path: str) -> None:
        """从本地存储服务或文件系统下载.

        Args:
            uri: 文件URI（支持 file://, http://, https://）
            local_path: 本地保存路径

        Raises:
            DownloadError: 下载失败
        """
        try:
            # 确保目标目录存在
            Path(local_path).parent.mkdir(parents=True, exist_ok=True)

            # 处理不同的URI协议
            if uri.startswith("file://"):
                # 本地文件系统，直接复制
                await self._download_from_filesystem(uri, local_path)
            elif uri.startswith(("http://", "https://")):
                # 本地存储服务，通过HTTP下载
                await self._download_from_http(uri, local_path)
            else:
                raise DownloadError(f"不支持的URI格式: {uri}")

            self.logger.info(f"成功下载文件: {uri} -> {local_path}")

        except Exception as e:
            self.logger.error(f"下载文件失败 {uri}: {e}")
            raise DownloadError(f"下载失败: {e}") from e

    async def _download_from_filesystem(self, uri: str, local_path: str) -> None:
        """从文件系统复制文件"""
        source_path = uri[7:]  # 移除 file:// 前缀
        shutil.copy2(source_path, local_path)

    async def _download_from_http(self, uri: str, local_path: str) -> None:
        """通过HTTP下载文件"""
        async with aiohttp.ClientSession() as session:
            async with session.get(uri) as response:
                if response.status == 200:
                    with open(local_path, 'wb') as f:
                        f.write(await response.read())
                else:
                    raise DownloadError(f"HTTP下载失败: {response.status}")

    async def upload_file(
        self,
        local_path: str,
        user_id: str,
        chat_id: str,
        channel_type: str
    ) -> str:
        """上传文件到本地存储.

        Args:
            local_path: 本地文件路径
            user_id: 用户ID
            chat_id: 会话ID
            channel_type: 渠道类型

        Returns:
            本地存储URI（http://localhost:... 或 file://）

        Raises:
            UploadError: 上传失败
        """
        try:
            from datetime import datetime, timezone

            # 确保文件存在
            if not Path(local_path).exists():
                raise UploadError(f"本地文件不存在: {local_path}")

            # 清理 chat_id
            try:
                cleaned_chat_id = sanitize_chat_id(chat_id, channel_type)
            except ValueError as e:
                raise UploadError(f"Invalid chat_id: {e}") from e

            # 构建对象Key
            timestamp = datetime.now(timezone.utc).strftime("%Y%m%d_%H%M%S")
            filename = Path(local_path).name

            object_key = build_object_key(
                user_id=user_id,
                channel_type=channel_type,
                chat_id=cleaned_chat_id,
                timestamp=timestamp,
                filename=filename
            )

            # 目标路径
            target_path = self.base_dir / object_key
            target_path.parent.mkdir(parents=True, exist_ok=True)

            # 复制文件
            shutil.copy2(local_path, target_path)

            # 构建返回URI
            uri = f"file://{target_path}"

            self.logger.info(
                f"成功上传文件到本地存储: {local_path} -> {uri} "
                f"(user={user_id}, channel={channel_type}, chat={cleaned_chat_id})"
            )
            return uri

        except Exception as e:
            self.logger.error(
                f"上传文件失败 {local_path} "
                f"(user={user_id}, channel={channel_type}, chat={chat_id}): {e}"
            )
            raise UploadError(f"上传失败: {e}") from e

    async def delete_chat_files(
        self,
        user_id: str,
        chat_id: str,
        channel_type: str,
        older_than_hours: Optional[int] = None
    ) -> int:
        """删除指定会话的所有文件."""
        try:
            import time
            from datetime import datetime, timezone

            # 清理 chat_id
            try:
                cleaned_chat_id = sanitize_chat_id(chat_id, channel_type)
            except ValueError as e:
                raise UploadError(f"Invalid chat_id: {e}") from e

            # 构建前缀
            chat_prefix = f"{channel_type}_{cleaned_chat_id}"
            prefix = f"files/{user_id}/{chat_prefix}/"

            # 计算时间阈值
            time_threshold = None
            if older_than_hours is not None:
                time_threshold = time.time() - (older_than_hours * 3600)

            deleted_count = 0

            # 查找并删除文件
            if not self.base_dir.exists():
                return 0

            for file_path in self.base_dir.rglob("*"):
                if not file_path.is_file():
                    continue

                # 检查文件路径是否匹配前缀
                try:
                    relative_path = file_path.relative_to(self.base_dir)
                    if not str(relative_path).startswith(prefix):
                        continue
                except ValueError:
                    continue

                # 检查时间过滤
                if older_than_hours is not None:
                    file_mtime = file_path.stat().st_mtime
                    if file_mtime > time_threshold:
                        continue

                # 删除文件
                file_path.unlink()
                deleted_count += 1

            self.logger.info(
                f"删除了 {deleted_count} 个本地文件 "
                f"(user={user_id}, channel={channel_type}, chat={cleaned_chat_id})"
            )
            return deleted_count

        except Exception as e:
            self.logger.error(
                f"删除本地会话文件失败 "
                f"(user={user_id}, channel={channel_type}, chat={chat_id}): {e}"
            )
            raise UploadError(f"删除失败: {e}") from e

    async def delete_user_files(
        self,
        user_id: str,
        older_than_hours: int = 24
    ) -> int:
        """批量删除用户的旧文件."""
        try:
            import time

            # 构建前缀
            prefix = f"files/{user_id}/"

            # 计算时间阈值
            time_threshold = time.time() - (older_than_hours * 3600)
            deleted_count = 0

            # 查找并删除文件
            if not self.base_dir.exists():
                return 0

            for file_path in self.base_dir.rglob("*"):
                if not file_path.is_file():
                    continue

                # 检查文件路径是否匹配前缀
                try:
                    relative_path = file_path.relative_to(self.base_dir)
                    if not str(relative_path).startswith(prefix):
                        continue
                except ValueError:
                    continue

                # 检查时间过滤
                file_mtime = file_path.stat().st_mtime
                if file_mtime > time_threshold:
                    continue

                # 删除文件
                file_path.unlink()
                deleted_count += 1

            self.logger.info(
                f"删除了 {deleted_count} 个超过 {older_than_hours}h 的本地文件 "
                f"(user={user_id})"
            )
            return deleted_count

        except Exception as e:
            self.logger.error(f"删除本地用户文件失败 (user={user_id}): {e}")
            raise UploadError(f"删除失败: {e}") from e
```

```python
class ObsStorageBackend(BaseStorageBackend):
    """华为云 OBS 存储后端"""

    def _validate_config(self, config: dict) -> dict:
        """OBS 特定配置验证"""
        super()._validate_config(config)

        required_fields = ["access_key", "secret_key", "bucket"]
        missing = [field for field in required_fields if not config.get(field)]

            raise ValueError(f"OBS 配置不完整，缺少: {', '.join(missing)}")

        try:
            from obs import ObsClient
            client = ObsClient(
                access_key_id=self.access_key,
                secret_access_key=self.secret_key,
                server=self.endpoint,
            )
            self.logger.info("OBS client created successfully")
            return client
        except ImportError:
            raise ImportError("未安装 esdk-obs-py SDK，请运行：pip install esdk-obs-py")
        except Exception as e:
            raise UploadError(f"创建 OBS 客户端失败: {e}")

    def _test_connection(self):
        """测试 OBS 连接"""
        try:
            client = self._get_client()
            client.listBuckets()
        except Exception as e:
            self.logger.warning(f"OBS 连接测试失败: {e}")
```

## 文件隔离机制

### CHAT_ID 级别隔离（v2.0）

**设计原则**：使用 `user_id + chat_id + channel_type` 进行文件隔离，实现会话级别的文件管理。

**路径结构**：
```
对象存储路径结构：
bucket: jiuwenclaw-data
└── files/
    └── {user_id}/                          # 用户ID
        └── {channel_type}_{chat_id}/       # 渠道_会话ID（已清理）
            └── {YYYYMMDD_HHMMSS}/          # 上传时间戳
                └── filename.ext

示例URI：
https://obs.../files/alice/web_chat456/20250511_143052/image.jpg
                    ↑     ↑         ↑
                  user_id channel+chat 时间戳
```

**chat_id 清理规则**（通过 `sanitize_chat_id()` 实现）：
- 移除特殊字符（除 `-` 和 `_`）
- 替换 `/` 为 `-`
- 限制长度为64字符
- 确保以字母开头

**工具函数**：
```python
from jiuwenclaw.storage.utils import sanitize_chat_id, build_object_key

# 清理 chat_id
cleaned_id = sanitize_chat_id("chat/456", "web")
# 返回: "web_chat-456"

# 构建对象Key
object_key = build_object_key(
    user_id="alice",
    channel_type="web",
    chat_id="chat456",
    timestamp="20250511_143052",
    filename="image.jpg"
)
# 返回: "files/alice/web_chat456/20250511_143052/image.jpg"
```

**优势**：
- 不同用户的文件完全隔离
- 同一用户的不同会话文件分离
- 支持会话级别的文件清理
- 历史消息中的文件URI永久可访问
- 灵活支持多渠道（web, websocket等）

```python
# jiuwenclaw/storage/backend.py

from abc import ABC, abstractmethod

class BaseStorageBackend(ABC):
    """
    🎯 简化的存储后端抽象基类 - v2.0

    核心职责：
    1. download_file(): 从对象存储URI下载文件到本地workspace
    2. upload_file(): 上传本地文件到对象存储，返回URI
    3. delete_chat_files(): 删除指定会话的文件
    4. delete_user_files(): 删除用户的文件

    设计原则：
    - 简单：只有4个核心方法
    - 内部：仅AgentServer内部使用
    - 无状态：不维护会话状态
    - 隔离：使用 user_id + chat_id + channel_type 进行文件隔离
    """

    @abstractmethod
    async def download_file(
        self,
        uri: str,           # 对象存储URI（来自E2AEnvelope.params.files）
        local_path: str,    # 本地保存路径（Agent workspace）
    ) -> None:
        """
        从对象存储下载文件到本地workspace

        支持的URI格式：
            - https://obs... (华为云OBS)
            - https://oss... (阿里云OSS)
            - http://... (本地存储服务)
            - file://... (本地文件系统)

        使用场景:
            AgentServer收到E2AEnvelope.params.files后，
            需要下载文件到workspace供Agent使用
        """
        pass

    @abstractmethod
    async def upload_file(
        self,
        local_path: str,    # Agent生成的本地文件
        user_id: str,       # 用户ID（用于路径隔离）
        chat_id: str,       # 会话ID（用于会话级隔离）
        channel_type: str,  # 渠道类型（web, websocket等）
    ) -> str:              # 返回对象存储URI
        """
        上传本地文件到对象存储

        参数：
            local_path: 本地文件路径
            user_id: 用户ID
            chat_id: 会话ID（会被清理和验证）
            channel_type: 渠道类型

        返回:
            对象存储URI（https://obs:// 或 https://oss://）

        使用场景:
            Agent生成文件后，需要上传到对象存储
            URI通过E2AResponse返回给前端
        """
        pass

    @abstractmethod
    async def delete_chat_files(
        self,
        user_id: str,
        chat_id: str,
        channel_type: str,
        older_than_hours: Optional[int] = None
    ) -> int:
        """
        删除指定会话的文件

        返回删除的文件数量
        """
        pass

    @abstractmethod
    async def delete_user_files(
        self,
        user_id: str,
        older_than_hours: int = 24
    ) -> int:
        """
        删除用户的文件

        返回删除的文件数量
        """
        pass
```

```python
class JiuWenClaw:

    def __init__(self, ...):

        self._storage = StorageService.get_instance()

    async def _prepare_input_files(
        self,
        envelope: E2AEnvelope,
        workspace_dir: str,
    ):
        """
        预处理输入文件：从对象存储下载到本地workspace

        调用时机：process_message开始之前

        输入：envelope.params.files = [{uri: "https://obs.../img.jpg"}]
        输出：修改params，添加path字段
        """
        if "files" not in envelope.params:
            return

        user_id = envelope.user_id or "default"

        for file_info in envelope.params["files"]:
            uri = file_info.get("uri") or file_info.get("url")
            if not uri:
                continue

            # 构建本地路径（仅使用 user_id）
            filename = file_info.get("name", "unknown_file")
            local_path = self._build_local_path(
                workspace_dir, user_id, "input", filename
            )

            try:
                # 调用存储接口下载
                await self._storage.download_file(uri=uri, local_path=local_path)

                # 添加本地路径到file_info
                file_info["path"] = local_path

            except Exception as e:
                logger.error(f"Failed to download file {uri}: {e}")
                # 可选：移除失败的文件引用
```

### 输出文件处理（上传）

```python
# jiuwenclaw/agentserver/interface.py

class JiuWenClaw:

    async def _handle_output_files(
        self,
        response: AgentResponse,
        user_id: str,
        chat_id: str,
        channel_type: str,
    ):
        """
        后处理输出文件：上传到对象存储

        调用时机：process_message结束之前

        输入：response可能包含本地文件路径
        输出：修改response，添加uri字段
        """
        # 提取Agent生成的文件路径
        local_files = self._extract_generated_files(response)

        if not local_files:
            return

        uploaded_files = []

        for local_path in local_files:
            try:
                # 调用存储接口上传（使用 user_id + chat_id + channel_type）
                uri = await self._storage.upload_file(
                    local_path=local_path,
                    user_id=user_id,
                    chat_id=chat_id,
                    channel_type=channel_type
                )

                uploaded_files.append({
                    "path": local_path,
                    "uri": uri
                })

            except Exception as e:
                logger.error(f"Failed to upload file {local_path}: {e}")

        # 更新response
        if response.payload:
            response.payload["files"] = uploaded_files
```

### 抽象基类结构

```python
class BaseStorageBackend(ABC):
    """🎯 简化的存储后端抽象基类"""

    def __init__(self, config: dict):
        # 1. 配置验证
        self.config = self._validate_config(config)
        
        # 2. 基础属性
        self.access_key = self.config.get("access_key", "")
        self.secret_key = self.config.get("secret_key", "")
        self.bucket = self.config.get("bucket", "")
        
        # 3. 懒加载客户端
        self._client = None

    def _validate_config(self, config: dict) -> dict:
        """🔒 配置验证 - 子类可重写"""
        if not isinstance(config, dict):
            raise ValueError("配置必须是字典类型")
        return config

    def _get_client(self):
        """🔧 客户端获取（懒加载）"""
        if self._client is None:
            self._client = self._create_client()
            self._test_connection()
        return self._client

    @abstractmethod
    def _create_client(self):
        """🏗️ 客户端创建 - 子类必须实现"""
        pass

    def _test_connection(self):
        """🔌 连接测试 - 子类可重写"""
        pass

    # 核心业务方法
    @abstractmethod
    async def upload_file(self, local_path: str, user_id: str, 
                         chat_id: str, channel_type: str) -> str:
        """上传文件"""
        pass

    @abstractmethod
    async def download_file(self, uri: str, local_path: str) -> None:
        """下载文件"""
```

### AWS S3 存储实现

```python
"""AWS S3 存储后端实现"""

import asyncio
from pathlib import Path
from datetime import datetime, timezone
from typing import Optional

from jiuwenclaw.storage.backend import BaseStorageBackend
from jiuwenclaw.storage.exceptions import UploadError, DownloadError
from jiuwenclaw.storage.utils import sanitize_chat_id, build_object_key


class S3StorageBackend(BaseStorageBackend):
    """AWS S3 存储后端"""

    def _validate_config(self, config: dict) -> dict:
        """S3 特定配置验证"""
        super()._validate_config(config)

        required_fields = ["access_key", "secret_key", "bucket", "region"]
        missing = [field for field in required_fields if not config.get(field)]
        if missing:
            raise ValueError(f"S3 配置不完整，缺少: {', '.join(missing)}")

        # 设置默认 region
        if not config.get("region"):
            config["region"] = "us-east-1"

        return config

    def _create_client(self):
        """创建 S3 客户端"""
        try:
            import boto3

            client = boto3.client(
                's3',
                aws_access_key_id=self.access_key,
                aws_secret_access_key=self.secret_key,
                region_name=self.region
            )
            self.logger.info("S3 client created successfully")
            return client

        except ImportError:
            raise ImportError("请安装 boto3: pip install boto3")
        except Exception as e:
            raise UploadError(f"创建 S3 客户端失败: {e}")

    def _test_connection(self):
        """测试 S3 连接"""
        try:
            client = self._get_client()
            client.head_bucket(Bucket=self.bucket)
        except Exception as e:
            self.logger.warning(f"S3 连接测试失败: {e}")

    async def upload_file(self, local_path: str, user_id: str, 
                         chat_id: str, channel_type: str) -> str:
        """上传文件到 S3"""
        from jiuwenclaw.storage.utils import sanitize_chat_id, build_object_key
        
        cleaned_chat_id = sanitize_chat_id(chat_id, channel_type)
        timestamp = datetime.now(timezone.utc).strftime("%Y%m%d_%H%M%S")
        filename = Path(local_path).name

        # 构建对象Key
        object_key = build_object_key(
            user_id=user_id,
            channel_type=channel_type,
            chat_id=cleaned_chat_id,
            timestamp=timestamp,
            filename=filename
        )

        # 上传文件
        loop = asyncio.get_event_loop()
        await loop.run_in_executor(
            None,
            lambda: self._get_client().upload_file(
                self.bucket, object_key, local_path
            )
        )

        # 返回URI
        uri = f"https://{self.bucket}.s3.{self.region}.amazonaws.com/{object_key}"
        self.logger.info(f"Uploaded to S3: {local_path} -> {uri}")
        return uri

    async def download_file(self, uri: str, local_path: str) -> None:
        """从 S3 下载文件"""
        object_key = self._parse_uri(uri)
        Path(local_path).parent.mkdir(parents=True, exist_ok=True)

        loop = asyncio.get_event_loop()
        await loop.run_in_executor(
            None,
            lambda: self._get_client().download_file(
                self.bucket, object_key, local_path
            )
        )

        self.logger.info(f"Downloaded from S3: {uri} -> {local_path}")

    async def delete_chat_files(self, user_id: str, chat_id: str, 
                               channel_type: str, 
                               older_than_hours: Optional[int] = None) -> int:
        """删除会话文件"""
        from jiuwenclaw.storage.utils import sanitize_chat_id
        
        cleaned_chat_id = sanitize_chat_id(chat_id, channel_type)
        prefix = f"files/{user_id}/{channel_type}_{cleaned_chat_id}/"
        return await self._delete_by_prefix(prefix, older_than_hours)

    async def delete_user_files(self, user_id: str, 
                               older_than_hours: int = 24) -> int:
        """删除用户文件"""
        prefix = f"files/{user_id}/"
        return await self._delete_by_prefix(prefix, older_than_hours)

    async def _delete_by_prefix(self, prefix: str, 
                               older_than_hours: Optional[int]) -> int:
        """按前缀删除的通用方法"""
        import time
        import asyncio

        client = self._get_client()
        deleted_count = 0

        # 列出对象
        loop = asyncio.get_event_loop()
        response = await loop.run_in_executor(
            None,
            lambda: client.list_objects_v2(Bucket=self.bucket, Prefix=prefix)
        )

        if 'Contents' not in response:
            return 0

        # 删除对象
        for obj in response['Contents']:
            # 时间过滤
            if older_than_hours is not None:
                obj_time = obj['LastModified'].timestamp()
                if time.time() - obj_time < older_than_hours * 3600:
                    continue

            # 删除
            await loop.run_in_executor(
                None,
                lambda o=obj: client.delete_object(Bucket=self.bucket, Key=o['Key'])
            )
            deleted_count += 1

        return deleted_count

    def _parse_uri(self, uri: str) -> str:
        """解析 S3 URI"""
        # https://bucket.s3.region.amazonaws.com/key
        prefix = f"https://{self.bucket}.s3.{self.region}.amazonaws.com/"
        if uri.startswith(prefix):
            return uri[len(prefix):]
        raise ValueError(f"无效的 S3 URI: {uri}")
```

## 扩展机制 (v3.0)

### 概述

v3.0引入了 **StorageBackendRegistry** 和 **backend_class 配置字段**，实现了非入侵式Backend扩展。用户无需修改SDK源码，只需继承 `BaseStorageBackend` 并在配置文件中指定Backend类路径，SDK会自动发现并加载。

### StorageBackendRegistry

#### 核心功能

`StorageBackendRegistry` 提供混合注册机制：

1. **手动注册** - SDK内置Backend自动注册
2. **配置驱动注册** - 用户通过 `backend_class` 字段自动注册

#### 主要方法

```python
from jiuwenclaw.storage import StorageBackendRegistry

# 1. 手动注册Backend类
StorageBackendRegistry.register("local", LocalStorageBackend)

# 2. 配置驱动注册（读取backend_class字段）
config = {
    "type": "my_backend",
    "backend_class": "my_package.my_module.MyStorageBackend",
    "root_path": "/data/storage"
}
StorageBackendRegistry.register_from_config(config)

# 3. 获取已注册的Backend类
backend_class = StorageBackendRegistry.get("my_backend")

# 4. 列出所有已注册Backend
available = StorageBackendRegistry.list_available()
# 返回：["local", "obs", "oss", "my_backend"]

# 5. 重置注册表（测试用）
StorageBackendRegistry.reset()
```

#### 内置Backend自动注册

SDK内置的 `LocalStorageBackend` 在 `jiuwenclaw/storage/__init__.py` 中自动注册：

```python
# jiuwenclaw/storage/__init__.py

from jiuwenclaw.storage.registry import StorageBackendRegistry
from jiuwenclaw.storage.backends.local import LocalStorageBackend

# 自动注册内置LocalStorageBackend
```

### backend_class 配置字段

#### 配置格式

```python
class StorageService:
    def _create_backend(self, storage_config: dict):
        """创建Backend实例"""
        backend_type = storage_config.get("type", "local")

        # 1. 执行配置驱动注册
        StorageBackendRegistry.register_from_config(storage_config)

        # 2. 从Registry获取Backend类
        backend_class = StorageBackendRegistry.get(backend_type)

        if backend_class is None:
            raise ValueError(f"未注册的Backend类型: {backend_type}")

        # 3. 实例化Backend
        return backend_class(storage_config)
```

### 用户扩展Backend示例

#### 步骤1：继承BaseStorageBackend

```python
# my_package/my_module.py

from pathlib import Path
import shutil
from jiuwenclaw.storage import BaseStorageBackend
from jiuwenclaw.storage.exceptions import UploadError

class MyStorageBackend(BaseStorageBackend):
    """我的自定义存储后端"""

    def _validate_config(self, config: dict) -> dict:
        """验证配置"""
        super()._validate_config(config)

        # 验证自定义配置字段
        root_path = config.get("root_path")
        if not root_path:
            # 使用默认值
            config["root_path"] = "/tmp/my-storage"

        # 创建目录
        Path(config["root_path"]).mkdir(parents=True, exist_ok=True)

        return config

    def _create_client(self):
        """创建客户端（本地存储无需客户端）"""
        return self

    def _validate_path_security(self, file_path: Path):
        """路径安全验证（防止路径穿越攻击）"""
        resolved_path = file_path.resolve()
        if not str(resolved_path).startswith(str(self.root_path.resolve())):
            raise UploadError(f"路径穿越攻击检测: {file_path}")

    async def upload_file(
        self,
        local_path: str,
        user_id: str,
        chat_id: str,
        channel_type: str
    ) -> str:
        """上传文件"""
        from datetime import datetime

        # 构造目标路径
        timestamp = datetime.now().strftime("%Y%m%d_%H%M%S")
        dest_dir = self.root_path / "files" / user_id / f"{channel_type}_{chat_id}" / timestamp
        dest_dir.mkdir(parents=True, exist_ok=True)

        # 复制文件
        local_file = Path(local_path)
        dest_file = dest_dir / local_file.name
        shutil.copy2(local_file, dest_file)

        # 路径安全验证
        self._validate_path_security(dest_file)

        # 返回file:// URI
        return f"file://{dest_file}"

    async def download_file(self, uri: str, local_path: str) -> None:
        """下载文件"""
        # 解析URI
        file_path = Path(uri.replace("file://", ""))

        # 验证路径安全
        self._validate_path_security(file_path)

        # 复制文件
        shutil.copy2(file_path, Path(local_path))

    async def delete_chat_files(
        self,
        user_id: str,
        chat_id: str,
        channel_type: str,
        older_than_hours: Optional[int] = None
    ) -> int:
        """删除会话文件"""
        import os
        import time

        chat_dir = self.root_path / "files" / user_id / f"{channel_type}_{chat_id}"
        if not chat_dir.exists():
            return 0

        deleted_count = 0
        cutoff_time = time.time() - (older_than_hours * 3600) if older_than_hours else None

        for file_path in chat_dir.rglob("*"):
            if file_path.is_file():
                if cutoff_time and file_path.stat().st_mtime < cutoff_time:
                    file_path.unlink()
                    deleted_count += 1

        return deleted_count

    async def delete_user_files(
        self,
        user_id: str,
        older_than_hours: int = 24
    ) -> int:
        """删除用户文件"""
        user_dir = self.root_path / "files" / user_id
        if not user_dir.exists():
            return 0

        deleted_count = 0
        cutoff_time = time.time() - (older_than_hours * 3600)

        for file_path in user_dir.rglob("*"):
            if file_path.is_file():
                if file_path.stat().st_mtime < cutoff_time:
                    file_path.unlink()
                    deleted_count += 1

        return deleted_count
```

### AgentServer文件处理优化

#### inputs["files"] 直接传递

AgentServer在调用Agent前，会将前端传来的文件直接传递给Agent：

```python
# jiuwenclaw/agentserver/interface.py

class JiuWenClaw:
    def _build_inputs(self, request: AgentRequest):
        inputs = {
            "query": request.params.get("query"),
            "files": request.params.get("files", []),  # 直接传递
            ...
        }
        return inputs, memory_mode, raw_query
```

**Agent访问文件**：

```python
# Agent代码
async def process_message_impl(request, inputs):
    files = inputs.get("files", [])

    # 字典格式
    if isinstance(files, dict):
        for file_key, file_ref in files.items():
            path = file_ref.get("path")
            if path and Path(path).exists():
                # 读取文件
                content = Path(path).read_text()

    # 列表格式
    elif isinstance(files, list):
        for file_ref in files:
            path = file_ref.get("path")
            if path and Path(path).exists():
                # 读取文件
                content = Path(path).read_text()
```

#### payload.files 统一结构

Agent返回文件时使用统一结构 `{path, name, uri}`：

```python
# Agent代码
async def process_message_impl(request, inputs):
    # 生成输出文件
    output_file = Path("/tmp/result.txt")
    output_file.write_text("处理结果")

    return AgentResponse(
        request_id=request.request_id,
        channel_id=request.channel_id,
        ok=True,
        payload={
            "content": "处理完成",
            "files": [
                {
                    "path": str(output_file),
                    "name": "result.txt"
                    # uri 由 AgentServer 自动添加
                }
            ]
        }
    )
```

**AgentServer处理**：

```python
# jiuwenclaw/agentserver/interface.py

class JiuWenClaw:
    async def upload_agent_files(self, response, user_id, chat_id, channel_type):
        files = response.payload.get("files", [])

        for file_info in files:
            local_path = file_info.get("path")

            # 检查文件是否存在
            if not Path(local_path).exists():
                self.logger.warning(f"文件不存在，跳过上传: {local_path}")
                continue

            # 自动补充 name 字段
            if "name" not in file_info:
                file_info["name"] = Path(local_path).name

            # 上传文件并添加 uri
            uri = await self._storage.upload_file(
                local_path, user_id, chat_id, channel_type
            )
            file_info["uri"] = uri
```
