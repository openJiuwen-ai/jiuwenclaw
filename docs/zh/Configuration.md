# 配置指南（Configuration）

本文档说明 JiuwenSwarm 的配置入口与核心配置项。

## 配置入口

在「配置信息」页面可查看和管理配置，主要包含：

- 模型配置
- 安全配置
- 其他配置

## 模型配置

配置 Agent 使用的模型服务：

- **模型服务地址**：填写模型服务的 endpoint
- **API Key**：填写访问凭证
- **模型选择**：选择会话使用的模型

配置完成后可点击「测试连接」验证配置是否可用。

## 安全配置

- 工具权限控制：限制 Agent 可调用的工具范围
- 敏感操作确认：高风险操作需要用户确认

## 其他配置

- 上下文压缩开关
- 记忆（Memory）相关配置
- 技能演进（Skill Self-Evolution）开关

## 配置生效方式

> **注意**：部分配置（如模型服务地址）修改保存后需要**重启服务**才生效。

```bash
uv run jiuwenswarm-start
```

如修改后未生效，请重启服务后再试。

## 常见问题

### 配置保存后对话仍使用旧模型

- 请重启服务后再发起对话
- 检查模型服务地址与 API Key 是否正确

### 无法连接模型服务

- 使用「测试连接」定位问题
- 检查网络与代理配置
- 查看 `~/.jiuwenswarm/logs/` 下的运行日志
