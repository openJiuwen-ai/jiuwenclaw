# Agent & workspace

`workspace` is JiuwenAvatar’s runtime directory for agent memory, skills, session data, and configurable heartbeat tasks. On first initialization (`init` or `app`), the bootstrap templates under `jiuwenavatar/resources/agent/workspace/` are copied to the user workspace at `~/.jiuwenavatar/agent/workspace/`.

Built-in skills are not stored in the workspace template. The versioned default Skill sources shipped with the repository live under `jiuwenavatar/resources/avatar-skills/`; persona-bound skills are installed from there into the user workspace when needed.

## Layout overview

The user workspace layout (`~/.jiuwenavatar/agent/workspace/`):

```
workspace/
├── agent-data.json        # Agent list metadata (generated by scripts/generate-agent-folders.js)
├── AGENT.md               # Agent identity (from AGENT_ZH.md or AGENT_EN.md at init)
├── HEARTBEAT.md           # Heartbeat tasks (from HEARTBEAT_ZH.md or HEARTBEAT_EN.md at init)
├── IDENTITY.md            # Identity (from IDENTITY_ZH.md or IDENTITY_EN.md at init)
├── SOUL.md                # Persona for system prompts (from SOUL_ZH.md or SOUL_EN.md at init)
├── USER.md                # User profile template
├── memory/                # Memory system
│   ├── MEMORY.md          # Long-term memory (from MEMORY_ZH.md or MEMORY_EN.md at init)
│   ├── YYYY-MM-DD.md      # Daily memory (generated)
│   ├── messages.json      # Compressed message store (generated)
│   └── memory.db          # ChromaDB vector store (generated)
├── skills/                # Marketplace/installed skills and skills_state.json
│   ├── skills_state.json  # Skill install/market state (copied from resources/skills_state.json at init)
│   ├── _marketplace/      # Marketplace clone cache
│   └── <skill-name>/      # Per-skill directory
├── todo/                  # Todo data (generated)
├── messages/              # Message data (generated)
├── agents/                # Agent-related data (generated)
└── session/               # Sessions (generated)
    ├── sess_<id>/         # Normal sessions
    └── heartbeat_<id>/    # Heartbeat sessions
```

## Package resource responsibilities

| Path | Purpose | Tracked in Git |
|------|---------|----------------|
| `jiuwenavatar/resources/agent/workspace/*.md` | Bootstrap templates for AGENT, HEARTBEAT, IDENTITY, SOUL, and USER | Yes |
| `jiuwenavatar/resources/agent/workspace/memory/*.md` | Bootstrap MEMORY templates | Yes |
| `jiuwenavatar/resources/avatar-skills/` | Versioned built-in Skill sources used by persona-bound skill installation | Yes |
| `jiuwenavatar/resources/skills_state.json` | Initial skill state copied to the user `skills/skills_state.json` | Yes |
| `jiuwenavatar/resources/agent/workspace/skills/` | Historical/development-generated compatibility path, not the authoritative built-in skill source | No |
| `jiuwenavatar/resources/agent/workspace/agent-data.json` | Web file-tree index generated by scripts | No |

At runtime, `get_builtin_skills_dirs()` scans `resources/avatar-skills/` first, then keeps compatibility with `resources/agent/workspace/skills/` and legacy `resources/agent/skills/`.

## Pre-configured content

Shipped with the package or source; you can use or edit as needed:

| Path (in workspace) | Description |
|------|-------------|
| `HEARTBEAT.md` | Heartbeat template (`jiuwenavatar/resources/agent/workspace/HEARTBEAT_ZH.md` or `HEARTBEAT_EN.md`, copied by language at init). If present and valid, the agent reads it on each heartbeat; otherwise only `HEARTBEAT_OK` is returned. Editable in the web UI. |
| `SOUL.md` | Persona for system prompts. |
| `skills/` | Marketplace/installed skills. Each skill has `SKILL.md`, `prompts/`, `references/`, etc. |
| `skills/_marketplace/` | Marketplace clone cache. |
| `memory/` | Memory layout. `USER.md` and `memory/MEMORY.md` may be created on first use or copied from init templates. |

---

## Dynamically generated content

Created or updated at runtime:

| Path (in workspace) | Description |
|------|-------------|
| `agent-data.json` | Generated by `scripts/generate-agent-folders.js` for the web UI. |
| `skills/skills_state.json` | Maintained by `SkillManager` for installed marketplace plugins. |
| `memory/YYYY-MM-DD.md` | Daily memory files. |
| `memory/messages.json` | Compressed messages for memory. |
| `memory/memory.db` | ChromaDB for `memory_search`. |
| `skills/<skill>/evolutions.json` | Skill evolution records. |
| `session/<session_id>/` | One folder per session. |
| `session/<session_id>/*` | Other session artifacts. |

## Related configuration

- **Skill root**: `skill_base_dir` in `config/config.yaml`, default `agent/skills`.
- **Agent workspace**: `~/.jiuwenavatar/agent/workspace/` (`get_agent_workspace_dir()`).
- **Sessions**: `~/.jiuwenavatar/agent/sessions/`.
- **SkillNet usage in Swarm**: see [Skills.md §5](Skills.md#5-how-skills-installed-via-skillnet-are-used-in-claw).
