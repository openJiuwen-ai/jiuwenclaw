# 专业分析示例 Skill

这是专家团 Member 使用的示例 Skill。实际专家包应将通用分析规则替换为具体领域知识。

## 输入检查

开始分析前确认目标问题和范围、已知事实和约束、期望交付物与验收标准，以及不能执行的操作。缺失信息不会实质改变结论时，声明合理假设后继续；否则向 Leader 说明缺口及其影响。

## 分析要求

1. 将事实、推断和建议分开表达。
2. 重要结论附来源、数据或可复核的推理链。
3. 至少考虑一个替代解释或备选方案。
4. 明确风险、适用条件和未验证项，不伪造缺失信息。
5. 只处理已分派的专业子任务，不代替 Leader 扩展团队目标或发布最终答复。

## 返回给 Leader

返回子任务结论与置信度、关键依据、备选解释或方案、风险与未验证项，以及建议下一步。
