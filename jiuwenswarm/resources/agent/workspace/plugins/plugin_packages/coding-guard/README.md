# 编程防护 (Coding Guard)

编程安全插件：以只读安全审查分析代码、命令与文件风险，并由独立运行时门禁控制真实工具调用。审查 Tool 只提供建议，不决定执行；执行 Rail 在工具调用前独立拦截或征求确认。

## 核心能力

- **只读安全审查**：扫描代码、命令或工作区文件，识别密钥泄露、危险命令、动态执行等风险，返回证据与整改建议
- **密钥与凭据防护**：检测 API Key、AWS Access Key、私钥等敏感内容，并给出安全替代方案
- **命令执行护栏**：拦截或确认根目录递归删除、下载后直接执行、破坏性 Git 操作等高危命令
- **文件副作用门禁**：对写入、删除、移动等文件操作检查凭据文件、工作区边界与批量删除等风险场景

## 包内容

| 组件 | 类型 | 功能 |
| --- | --- | --- |
| `security_review_tool` | Tool | 只读审查代码、命令或工作区文件，返回风险发现与整改建议 |
| `execution_guard_rail` | Rail | 运行时门禁：`deny` 跳过工具，`require_approval` 征求确认，`warn` 放行并回传原因 |

### 安全审查覆盖项

| 类别 | 检查项 | 典型风险 |
| --- | --- | --- |
| 密钥 | API Key、AWS Access Key、私钥 | 凭据硬编码或泄露 |
| 命令 | 根目录递归删除、下载后直接执行 | 不可逆破坏或供应链攻击 |
| 代码 | `eval`/`exec` 动态执行、`shell=True` | 命令注入与任意代码执行 |

### 执行门禁策略

| 决策 | 行为 | 典型场景 |
| --- | --- | --- |
| `deny` | 拒绝执行 | 根目录递归删除、删除凭据/私钥文件 |
| `require_approval` | 暂停并征求用户确认 | 下载后执行、破坏性 Git、工作区外操作、写入疑似密钥内容 |
| `warn` | 放行并在结果中附加警告 | 低风险但需留痕的操作 |

## 使用方式

在 JiuwenSwarm 扩展安装并启用本插件，对话输入区勾选插件 chip，然后发送推荐问法即可触发对应能力。

推荐问法：

- 审查这段代码、命令或文件的安全风险，并给出整改建议。
- 检查工作区文件中的密钥、危险命令与不安全代码。
- 审查这段脚本并给出更安全的替代写法。
