# 编程防护（Coding Guard）

为编程任务提供执行前安全护栏：用户给出代码或文件时先扫描再结论；Agent 执行命令、写文件、删文件时按同一套策略拦截。

## 核心能力

- **先评估再动手**：对粘贴文本或工作区文件做静态扫描，返回风险等级、四级决策（allow / warn / confirm / block）、可执行性与逐条命中项。
- **拦住副作用**：工具调用前自动检查命令、路径与写入内容；删除密钥文件直接拦截，写入高可信密钥内容需确认，拒绝后向对应 tool-call 返回拦截结果。
- **一份策略、两端共用**：主动扫描与运行时拦截使用同一套规则与决策，结果带来源 `coding-guard` 与 `rule_id`，可与平台权限拦截区分。

## 使用方式

1. 在 JiuwenSwarm 插件中心安装并启用本插件，新对话输入区勾选插件 chip（可配合任意专家）。
2. 发送代码、命令或附件要求评估风险时，会先扫描再给出结论。
3. 运行时护栏对写删与命令执行自动生效，无需额外调用。
